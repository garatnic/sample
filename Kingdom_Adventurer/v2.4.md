## 確認事項と選択肢

<a id="q1"></a>

### 1. 敵AIの判断能力

- **採用** 種族・性格・経験・状況に応じて判断（推奨）
- **不採用** 種族ごとの固定行動パターン
- **不採用** 単純な接近・攻撃中心

<a id="q2"></a>

### 2. 敵対行動の発生条件

- **不採用** 生態・空腹・縄張り・関係性などに応じる（推奨）
- **採用** 魔物は基本的にすべて敵対
- **不採用** 攻撃されるまで敵対しない

<a id="q3"></a>

### 3. 逃走・降伏

- **採用** NPC・敵とも状況に応じて逃走・降伏（推奨）
- **不採用** 逃走のみ可能
- **不採用** 逃走・降伏なし

<a id="q4"></a>

### 4. 集団戦での連携

- **採用** 敵も仲間と連携し役割分担（推奨）
- **不採用** 各個体が独立して行動
- **不採用** リーダーの指示に従う集団行動中心

<a id="q5"></a>

### 5. 戦闘難易度の調整

- **採用** 難易度を調整可能、敵レベル連動はなし（推奨）
- **不採用** 固定難易度のみ
- **不採用** 難易度固定、操作補助のみ変更可能

Kingdom Adventurer — 仕様案 v2.4

成長・魔法仕様の確定／戦闘AI・敵の行動・戦闘バランス

v2.3の5項目を確定仕様に追加する。

今回の決定で、プレイヤー・仲間・敵が、それぞれの経験によって成長する世界という方針が固まった。

特に、敵も戦闘や生存によって強くなる点が重要。長年生き延びた魔物が、通常の個体よりはるかに強くなっている、といった状況を自然に作れる。

#### 1. v2.3で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 成長方式 | キャラクターレベル＋技能別熟練度 |
| 技能成長 | 使用経験＋訓練・教育 |
| 魔法体系 | 攻撃・回復・補助・召喚・生活魔法など |
| 魔法資源 | MP消費＋時間経過などによる回復 |
| 敵の成長 | 敵個体も経験・戦闘・生存によって成長 |

以前の「敵の強さはプレイヤーレベルに連動しない」という仕様も維持する。

つまり、プレイヤーがレベル50になったからといって、周囲のウサギやゴブリンが突然レベル50になることはない。

#### 2. 次のテーマ：戦闘AIと敵の行動

戦闘の基本は、通常攻撃が自動で、スキルは手動・自動を切り替えられるリアルタイム方式。

今回は、敵がどう判断して行動するか、集団戦をどう処理するか、戦闘の難易度をどう調整するかを決める。

敵の行動パターンの例

ゴブリン

仲間を呼び、数の優位を活かして攻撃する。劣勢になると逃走することもある。

オオカミ

群れで獲物を追い、孤立した相手を狙う。

オーガ

強力な近接攻撃を行うが、動きは遅い。

これらは行動例であり、まだ確定した敵種族の仕様ではない。

#### 3. 集団戦の考え方

戦闘時の役割分担例

主人公と仲間が役割を分担して戦うイメージ。

仲間のAI指示を細かく設定できることは既に確定している。

例えば、前衛は敵を引きつけ、後衛は遠距離攻撃、回復役は味方のHPを監視するといった運用が考えられる。

#### 4. v2.4で確定したい5項目

#### 5. 難易度調整についての補足

敵のレベルをプレイヤーに合わせて上げる方式は採用しない。

難易度を変更できるようにする場合は、敵の攻撃性、受けるダメージ、回復効果などのパラメータを調整する方式が考えられる。

これなら、レベルが高い敵は強く、弱い敵は弱いという世界の一貫性を維持できる。

ただし、難易度によってNPC同士の戦争や経済の結果まで大きく変わらないよう、プレイヤーの戦闘体験に関わる補正と世界シミュレーションの基礎能力値を分離する設計が望ましい。

次は、戦闘AIの仕様を確定した後、装備・戦利品・アイテム生成の詳細を検討する。
