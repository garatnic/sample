## 決定事項

> Kingdom Adventurer v3.7の農業・牧畜・採掘・生産・物流仕様として、農業：農地が一定時間ごとに食料を自動生産。牧畜：牧場施設が一定時間ごとに畜産物を生産。採掘：鉱床に採掘量と再生時間を設定し継続採掘可能。製造工程：原材料から完成品を直接製造。物流：近距離は商隊・船を実際に移動させ遠距離は簡易シミュレーション。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 農業の仕組み

- **不採用** 作物ごとに栽培期間・収穫量・季節適性を設定（推奨）
- **採用** 農地が一定時間ごとに食料を自動生産
- **不採用** 土壌・水分・肥料・天候まで細かく計算

<a id="q2"></a>

### 2. 牧畜の仕組み

- **不採用** 家畜の頭数・餌・繁殖・生産物を簡易管理（推奨）
- **不採用** 家畜を個体単位で管理し、成長・健康・繁殖を計算
- **採用** 牧場施設が一定時間ごとに畜産物を生産

<a id="q3"></a>

### 3. 鉱山・鉱床の資源量

- **採用** 採掘量と再生時間を設定し継続採掘可能（既存仕様に準拠）
- **不採用** 採掘によって枯渇し、再生しない
- **不採用** 資源量無制限で継続生産

<a id="q4"></a>

### 4. 製造・加工工程

- **不採用** 原材料・中間製品・完成品を区別し、製造時間と技能を反映（既存仕様に準拠）
- **採用** 原材料から完成品を直接製造
- **不採用** 施設が資源を消費せず一定時間ごとに商品を生産

<a id="q5"></a>

### 5. 商品の輸送方法

- **採用** 近距離は実際に移動、遠距離は簡易計算（既存仕様に準拠）
- **不採用** すべての輸送を実際の商隊・船で処理
- **不採用** 時間経過と費用だけで輸送を処理

Kingdom Adventurer — 仕様案 v3.7

生態系・資源循環仕様の確定／農業・牧畜・採掘・生産・物流

v3.6の5項目を確定仕様として整理する。

今回の決定で、自然環境は基本的に安定した状態を維持し、生態系の複雑な計算を省く方針になった。

一方、木材・植物・鉱石などの資源は時間と条件に応じて再生するため、長期間プレイしても採集活動を続けられる。

#### 1. v3.6で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 野生動物の個体数 | 基本的に一定数を維持 |
| 食物連鎖 | 見た目の演出のみ。個体数への影響は計算しない |
| 生息地域 | 生物の種類ごとに決まった地域に生息 |
| 採集資源 | 木材・植物・鉱石などが種類ごとの条件と時間で再生 |
| 環境変化 | 地域環境は基本的に変化しない |

既存仕様との整合

これまでに確定した「NPCによる伐採・採集」「建物の建築」「魔物の巣の再出現」は維持する。

つまり、木を伐採すればその木は一時的になくなり、時間が経てば再生する。建物を建てれば建物は残る。

ただし、森林全体が砂漠化したり、気候帯が変わったり、生態系が崩壊したりするような長期的な環境変化は原則として発生しない。

#### 2. 次のテーマ：農業・牧畜・採掘・生産・物流

このゲームの経済では、NPCが実際に資源を集め、加工し、商品を輸送して販売する。

既に次の基本仕様が決まっている。

原材料・中間製品・完成品には実際の在庫が存在する。

NPCは農業・採掘・製造・商業などの仕事を行う。

生産には資材や技能が関係する。

店舗や工房はNPCが自律的に運営できる。

商隊や船が商品を輸送する。

遠方の物流は簡略化して計算できる。

商品価格は地域ごとの需要と供給によって変動する。

今回は、生産活動をどの程度詳細に再現するかを決める。

#### 3. 生産と物流の流れ

鉄製武器が店頭に並ぶまで（例）

採掘

鉱山から鉄鉱石を採取する

鉱石を輸送

精錬・加工

鉄鉱石から鉄素材を製造する

素材を工房へ供給

鍛冶

職人が武器を製作する

完成品を出荷

販売

商店が在庫として保有し、NPCやプレイヤーに販売する

このような生産のつながりが成立すれば、例えば鉱山の生産量が減ると武器の供給が減り、価格が上昇する、といった経済的な変化が発生する。

ただし、すべての作業を個別に細かく再現する必要があるかは別問題。

#### 5. 今後の検討予定

v3.7の次は、商店・市場・価格・貨幣・経済バランスを詳しく検討する。

ここまで決めると、資源の採集から製造、物流、販売、消費までをつなぐ経済システムの主要仕様が固まる。
