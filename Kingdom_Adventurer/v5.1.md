## 確認事項と選択肢

<a id="q1"></a>
### 1. 住宅を置く空き区画がない場合

- **未決定・推奨** 集落周辺に道路と宅地を拡張して住宅を生成
- **未決定** 既存建物を上書きして住宅を生成
- **未決定** 空き区画ができるまで移住を禁止

<a id="q2"></a>
### 2. 住宅生成と景観の関係

- **未決定・推奨** 地域の建築様式・地形に応じて住宅の外観を変える
- **未決定** 世界中で同一の住宅モデルを使う
- **未決定** 住宅の見た目は完全にランダム

<a id="q3"></a>
### 3. 廃村化までの猶予期間

- **未決定・推奨** ゲーム内で一定日数の猶予を設け、その間に再入植すれば廃村化を回避
- **未決定** 人口がゼロになった瞬間に廃村化
- **未決定** 廃村化はプレイヤーが手動で指定

<a id="q4"></a>
### 4. 廃村跡への再入植

- **未決定・推奨** 旧集落の位置・道路・歴史を引き継ぎ新たな建物を生成して再建
- **未決定** 再入植時は別の場所に必ず新集落を作る
- **未決定** 廃村跡は永久に入植禁止

<a id="q5"></a>
### 5. 無制限住宅生成の対象

- **未決定・推奨** 無償・無資源生成は移住時の最低限住宅に限定し、増改築や他施設は通常ルール
- **未決定** 住宅の増改築とすべての施設も無償・無資源で生成
- **未決定** 移住住宅にも通常の建築費を課す

## 整合性と未解決点

- v5.0の移住時住宅は無償・無資源・数量上限なし。ただし空き区画と道路接続の配置条件がある。
- v5.0で定住人口ゼロが一定期間続くと廃村化、建物は削除するが道路・地形・土地履歴・年代記を保持すると確定。
- 本版は住宅の配置不能時、無償対象の範囲、廃村の猶予期間と再入植を具体化する。
