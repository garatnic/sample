## 確認事項と選択肢

<a id="q1"></a>
### 1. 契約更新なしでの家賃改定交渉

- **未決定・推奨** 契約は自動継続し、所有者または借主の提案があった時だけ家賃改定を交渉する
- **未決定** 家賃改定の交渉は永久に行わない
- **未決定** 毎日強制的に家賃改定交渉を行う

<a id="q2"></a>
### 2. 家賃改定の交渉頻度

- **未決定・推奨** 改定提案は同じ住宅につきゲーム内1年に1回までとする
- **未決定** 同じ所有者が毎日何度でも改定を要求できる
- **未決定** 改定提案は住宅ごとに一生1回だけ

<a id="q3"></a>
### 3. 家賃改定の不合意と退去処理

- **未決定・推奨** 交渉不成立で即時に契約終了・退去し、転居先の確保処理を開始する
- **未決定** 不合意でも旧契約を永久に継続する
- **未決定** 不合意時に住宅そのものを削除する

<a id="q4"></a>
### 4. 滞納債権移転の記録

- **未決定・推奨** 住宅の売買・相続時に債権者を新所有者へ変更し、移転前後の履歴を保存する
- **未決定** 債権者の変更履歴を残さない
- **未決定** 債権者を変更せず債権だけ複製する

<a id="q5"></a>
### 5. 退去後の未払い家賃

- **未決定・推奨** 退去後も未払い債務は残り、元の債権者への任意返済を続けられる
- **未決定** 退去した瞬間に未払い家賃をすべて帳消しにする
- **未決定** 退去した瞬間に全額強制徴収する

## 既存仕様との整合・検討課題
