## 確認事項と選択肢

<a id="q1"></a>
### 1. 家賃未払い額の記録

- **未決定・推奨** 滞納額は負債として記録するが契約継続・居住には影響させない
- **未決定** 滞納した家賃はその場で帳消しにする
- **未決定** 滞納額を記録せず毎月の支払いだけ判定する

<a id="q2"></a>
### 2. 家賃滞納分の回収

- **未決定・推奨** 入居者の資金に余裕ができた際に任意の返済・分割払いを行う
- **未決定** 家賃滞納分は強制徴収して所持金を必ずゼロにする
- **未決定** 滞納分の返済は一切認めない

<a id="q3"></a>
### 3. 賃貸契約の終了条件

- **未決定・推奨** 滞納以外の転居・合意解約・建物消滅などで終了する
- **未決定** 所有者が理由なく即時に強制退去させられる
- **未決定** 契約は建物消滅後も永久に継続する

<a id="q4"></a>
### 4. 廃村化時の賃貸契約

- **未決定・推奨** 住宅削除と同時に賃貸契約を終了し、過去の契約履歴は残す
- **未決定** 住宅がなくなっても毎月家賃を請求し続ける
- **未決定** 廃村化するとすべての住宅取引履歴も消去する

<a id="q5"></a>
### 5. 住宅所有者の収益の使い道

- **未決定・推奨** NPCは賃貸収益を通常の資産として生活・消費・投資に使う
- **未決定** 賃貸収益は住宅購入以外に使用できない
- **未決定** 賃貸収益は受領と同時に消滅する

## 既存仕様との整合

- v5.6で家賃は月払い、滞納は契約に影響せず、住宅売買には双方の合意と支払能力が必要と確定。
- v5.6で廃村化時に住宅所有権は消滅するが、土地・取引履歴は保持すると確定。
- v5.5で住宅所有者は複数住宅を自律的に賃貸運用できると確定。
