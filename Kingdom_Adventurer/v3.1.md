## 決定事項

> Kingdom Adventurer v3.1のギルド・組織・雇用・仲間仕様として、組織の自律性：NPCが組織を設立・運営・拡大・解散できる。組織への加入：複数組織に同時所属可能。ただし組織間の対立や規則による制約あり。プレイヤーの組織設立：資金・人員・拠点などの条件を満たせば自由に設立。雇用契約：定額の雇用費用だけを支払う。仲間の自律行動：仲間ごとに戦闘・探索・回復・撤退などの方針を設定可能。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. ギルド・組織の自律性

- **採用** NPCが組織を設立・運営・拡大・解散できる（推奨）
- **不採用** 初期配置された組織だけが活動する
- **不採用** 組織の設立・運営はプレイヤー中心

<a id="q2"></a>

### 2. 複数組織への所属

- **採用** 複数所属可能。ただし対立関係や規則による制約あり（推奨）
- **不採用** 常に1つの組織にしか所属できない
- **不採用** 組織間の対立を無視して無制限に加入可能

<a id="q3"></a>

### 3. プレイヤーによる組織設立

- **採用** 条件を満たせば自由に設立（推奨）
- **不採用** 決められた種類の組織のみ設立可能
- **不採用** 既存組織への加入・昇進のみ

<a id="q4"></a>

### 4. NPCとの雇用契約

- **不採用** 賃金・期間・役割・待遇を設定して交渉（推奨）
- **採用** 定額の雇用費用だけを支払う
- **不採用** 原則無期限・無給で雇用する

<a id="q5"></a>

### 5. 仲間への行動指示

- **採用** 仲間ごとに戦闘・探索・回復・撤退などの方針を設定（推奨）
- **不採用** パーティー全体に共通の方針のみ設定
- **不採用** 仲間がすべて独自判断し、プレイヤーは指示しない

Kingdom Adventurer — 仕様案 v3.1

領地・建築仕様の確定／ギルド・組織・雇用・仲間

v3.0の5項目を確定仕様に追加する。

今回の重要な決定は、領地や国家は基本的にNPCが自動運営するという点。

プレイヤーが国王や領主になっても、日々の建築・生産・雇用・経営を逐一指示する必要はない。自分の領地を持ちながら、自由に冒険を続けられる設計になる。

#### 1. v3.0で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 建築配置 | 地形・土地条件が許す範囲で自由配置 |
| 建築工程 | 資材・労働力・建築時間が必要 |
| 領地管理 | 基本的にNPCが自動運営 |
| 住民の建築 | NPCが需要・資金・土地に応じて自律建築 |
| 税制 | 税率・税目を設定でき、住民や経済に影響する |

自動運営とプレイヤーの権限

ここは区別しておく。

通常時： NPCが自律的に領地を運営する。

プレイヤーの介入： 建築、税制、経営方針などを変更できる。

プレイヤー不在時： 領地の活動は継続する。

自動運営を選択したからといって、プレイヤーが直接指示できなくなるわけではない。

ただし、NPCの判断にどこまで介入できるかという細部は、今後の検討事項として残す。

#### 2. 次のテーマ：ギルド・組織・雇用・仲間

国家や領地とは別に、世界にはさまざまな組織が存在する。

例えば、冒険者ギルドは魔物討伐の依頼を扱い、商人組合は交易を行い、傭兵団は報酬に応じて戦争に参加する。

これらの組織がNPCによって自律的に運営されれば、プレイヤーが関わらなくても組織同士の競争や協力が発生する。

想定する組織

冒険者ギルド

魔物討伐、護衛、探索、採集などの依頼を扱う。

商人組合・商会

商品の仕入れ、輸送、販売、商業拠点の運営を行う。

傭兵団

護衛、戦争への参加、拠点防衛などを請け負う。

職人組合

製造、加工、技術継承、材料の調達などを行う。

これらは組織の例であり、今回すべての種類を確定するわけではない。

#### 3. 仲間と雇用についての既存仕様

既に次の点は決まっている。

仲間の同時同行人数に固定上限はない。

仲間はそれぞれ経験を積んで成長する。

プレイヤーは仲間に個別の行動指示を出せる。

仲間を直接操作することはできない。

雇用・同行中の仲間は永久死亡しない。

雇用契約終了後は通常のNPCとして生活し、死亡する可能性がある。

今回は、仲間の人数や成長ではなく、組織の設立、加入、雇用契約、仲間の自律行動を具体化する。

#### 5. 今後の検討予定

v3.1の次は、NPCの生活・職業・家族・世代交代の詳細仕様を検討する。

特に、NPCが職業を変える条件、子供が成長して仕事に就く仕組み、家業や財産の相続、世代を超えた組織の継続などが未確定。

ここを整理すると、世界が何十年、何百年と自律的に変化していく仕組みを、さらに具体化できる。
