## 確認事項と選択肢

<a id="q1"></a>
### 1. NPC移住のきっかけ

- **未決定・推奨** 仕事・住居・安全・生活条件を比較してNPCが自律移住
- **未決定** 国家が移住命令を出した場合のみ移住
- **未決定** NPCは出生地から移住しない

<a id="q2"></a>
### 2. 開拓集落の発展

- **未決定・推奨** 人口・資源・交通・施設需要に応じて集落が自律成長
- **未決定** 一定期間ごとに集落が自動で一段階成長
- **未決定** 集落の成長はプレイヤーの建設指示のみ

<a id="q3"></a>
### 3. 領土拡張の優先順位

- **未決定・推奨** 資源・交通・防衛・人口需要を考慮して国家が拡張先を選ぶ
- **未決定** 最も近い未所属地域から順に拡張
- **未決定** ランダムに拡張先を決める

<a id="q4"></a>
### 4. 国境を越えるNPC移動

- **未決定・推奨** 平時は外交関係・治安・通行条件に応じて往来可能
- **未決定** 国境は常に自由通行
- **未決定** 国境は常に通行不可

<a id="q5"></a>
### 5. 年代記の記録粒度

- **未決定・推奨** 重要事件は詳細記録し日常的な出来事は要約して保存
- **未決定** すべてのNPC行動を無制限に詳細保存
- **未決定** 国家規模の事件だけ保存し人物の出来事は記録しない
