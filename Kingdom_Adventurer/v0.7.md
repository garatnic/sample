## 決定事項

> Kingdom Adventurer v0.7の戦闘仕様として、敵の強さ：世界環境・種族・成長で決定しプレイヤーレベルに連動しない。戦闘難易度：適度な危険性があり装備・育成が重要。プレイヤー死亡：拠点で復活し経験値・所持品を失う。仲間死亡：仲間は永久死亡しない。仲間AI：詳細な戦闘方針を設定可能。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 敵の強さ

- **採用** 世界環境・種族・成長で決定（推奨）
- **不採用** 地域ごとの固定難易度
- **不採用** プレイヤーレベルに連動

<a id="q2"></a>

### 2. 戦闘の難易度

- **採用** 適度な危険性・装備や育成が重要（推奨）
- **不採用** 探索重視で比較的簡単
- **不採用** 厳しい戦闘・戦術重視

<a id="q3"></a>

### 3. プレイヤー死亡時

- **不採用** 戦闘不能後に救助・復帰（推奨）
- **採用** 拠点で復活・所持品や経験値を損失
- **不採用** 直前のセーブから再開

<a id="q4"></a>

### 4. 仲間NPCの死亡

- **不採用** 救助可能だが条件次第で永久死亡（推奨）
- **不採用** HPゼロで即永久死亡
- **採用** 仲間は永久死亡しない

<a id="q5"></a>

### 5. 仲間の戦闘AI

- **採用** 詳細な戦闘方針を設定可能（推奨）
- **不採用** 攻撃・防御・支援など簡易方針
- **不採用** 完全自律・指示なし

## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

Kingdom Adventurer — 仕様案 v0.7

今回は、v0.6で選択した冒険システムを確定し、次の段階である戦闘・敵の強さ・死亡ペナルティ・仲間の戦闘AIを具体化しよう。

世界シミュレーションの基本設計はかなり固まってきたので、ここからは実際に遊んだときの面白さを左右する部分になる。

#### 1. v0.6で確定した仕様

| 分野 | 確定内容 |
| --- | --- |
| 探索 | 未探索地域は隠され、探索によって地図を開示 |
| 戦闘 | 通常攻撃は自動。スキルも自動使用を設定可能 |
| ダンジョン | 固定配置と自動生成を併用 |
| 装備 | 品質・ランダム性能・特殊効果あり |
| 成長 | 職業固定なし。自由なスキル成長 |

従来の確定仕様も維持する。

特に戦闘については、手動操作と自動化をプレイヤーが組み合わせられる方式になる。

例えば、通常攻撃と回復魔法は自動にして、強力な攻撃魔法だけ手動で使うこともできる。

#### 2. 半自動戦闘の基本構造

戦闘はフィールド上でそのまま発生する。専用の戦闘画面には切り替えない。

戦闘中の行動

| 行動 | 操作方法 |
| --- | --- |
| 移動 | プレイヤーが自由に操作 |
| 通常攻撃 | 射程内の敵へ自動攻撃 |
| 対象選択 | 自動選択＋手動指定 |
| スキル | 手動または自動使用を設定 |
| 魔法 | 手動または自動使用を設定 |
| 回復薬 | 手動使用。自動化は別途検討 |
| 逃走 | 移動によって戦闘から離脱 |
| 仲間 | 設定されたAI方針で行動 |

攻撃中でも移動できることを基本とし、操作の快適さを重視する。

#### 3. 敵の強さの設計

ここは特に重要。

単純に地域ごとに敵のレベルを固定すると、序盤の地域に戻る意味が薄くなる。

逆に、プレイヤーに合わせて敵が強くなると、成長の実感が失われる。

そこで、次のような仕組みを提案する。

敵の強さを決める要素

例えば、同じ森林でも普通の狼が多い地域に、長年生き残った強力な個体が現れることがある。

また、魔物の巣を放置すると勢力が拡大し、周辺の敵が強くなる。

つまり、地域の危険度は世界の状況によって変化するが、プレイヤーのレベルには直接連動しない。

#### 4. 仲間NPCの戦闘AI

同行するNPCは、単なる攻撃補助ではなく、それぞれの能力や性格を持つ。

前衛型

敵の注意を引き、味方を守る。勇敢なNPCは危険な敵にも立ち向かう。

遠距離型

距離を取りながら弓や魔法で攻撃する。

支援型

回復、強化、状態異常解除などを優先する。

これらは固定職業ではなく、装備、習得スキル、AI方針によって役割が変わる。

#### 5. 死亡ペナルティ

プレイヤーは死亡してもゲームを継続できることが確定している。

ただし、復活方法はまだ決めていない。

NPCには永久死亡があるため、プレイヤーとの違いを世界観の中でどう説明するかも検討したい。

例えば、死亡ではなく「戦闘不能になり、救助される」という仕組みにすれば、NPCとの整合性を取りやすい。

#### 6. 次に確定したい5項目

この段階では、戦闘に必要なアクションの種類や細かなダメージ計算式までは確定しない。

次は魔物の生態、繁殖、巣、ダンジョンを設計し、戦闘が世界シミュレーションと自然につながる仕組みを検討したい。
