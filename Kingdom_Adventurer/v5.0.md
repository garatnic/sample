## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。提示した全候補を残し、不採用案は再検討可能。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 無償生成される住居の仕様

- **採用・確定** 移住者の人数・家族構成に応じた最低限の住宅を自動生成
- **不採用（再検討可）** 全員に同じ大きさの住宅を生成
- **不採用（再検討可）** 移住時に豪華な住宅を無条件で生成

<a id="q2"></a>
### 2. 住居の生成場所

- **採用・確定** 空き区画と道路への接続を考慮して集落内・周辺に配置
- **不採用（再検討可）** 集落の中心に重ねて生成
- **不採用（再検討可）** 地形や既存建物を無視してランダム配置

<a id="q3"></a>
### 3. 廃村化の判定条件

- **採用・確定** 定住人口ゼロが一定期間継続したときに廃村化
- **不採用（再検討可）** 人口が1人でも減れば廃村化
- **不採用（再検討可）** 施設が1棟でも壊れたら廃村化

<a id="q4"></a>
### 4. 廃村時に残す情報

- **採用・確定** 建物は削除するが地形・道路・土地の履歴・年代記は残す
- **不採用（再検討可）** 建物とともに土地の履歴もすべて削除
- **不採用（再検討可）** 廃村化した地域そのものをマップから消す

<a id="q5"></a>
### 5. 住居無償生成の経済的扱い

- **不採用（再検討可）** 住居はNPCに無償だが世界の資源・建設能力を消費する
- **採用・確定** 住居は資源も費用も消費せず無制限に生成
- **不採用（再検討可）** 住居は移住者が必ず代金を支払う

## 既存仕様との整合

- v4.9で移住直後の無償住居生成と廃村時の建物全削除を採用。
- v4.4の国家滅亡時の住民・施設・歴史保持は廃村化と区別する。
- 建築資源の消費はv4.9で未確定のため、v5.0で明示的に選択する。

## 確定内容の補足

- 移住者の人数・家族構成に応じた最低限の住宅を自動生成する。
- 空き区画・道路接続を考慮して集落内または周辺に配置し、既存建物との重複を避ける。
- 定住人口ゼロが一定期間続いたとき廃村化する。期間の長さは未確定。
- 廃村化すると建物を削除するが、地形・道路・土地の履歴・年代記は保持する。国家滅亡だけでは施設を削除しない（v4.4）。
- **第5問は第2候補を採用**。移住時住宅は資源・費用を消費せず、数量上限を設けない。ただし空き区画や道路接続の配置条件は維持する。
