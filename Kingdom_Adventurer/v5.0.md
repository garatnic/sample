## 確認事項と選択肢

<a id="q1"></a>
### 1. 無償生成される住居の仕様

- **未決定・推奨** 移住者の人数・家族構成に応じた最低限の住宅を自動生成
- **未決定** 全員に同じ大きさの住宅を生成
- **未決定** 移住時に豪華な住宅を無条件で生成

<a id="q2"></a>
### 2. 住居の生成場所

- **未決定・推奨** 空き区画と道路への接続を考慮して集落内・周辺に配置
- **未決定** 集落の中心に重ねて生成
- **未決定** 地形や既存建物を無視してランダム配置

<a id="q3"></a>
### 3. 廃村化の判定条件

- **未決定・推奨** 定住人口ゼロが一定期間継続したときに廃村化
- **未決定** 人口が1人でも減れば廃村化
- **未決定** 施設が1棟でも壊れたら廃村化

<a id="q4"></a>
### 4. 廃村時に残す情報

- **未決定・推奨** 建物は削除するが地形・道路・土地の履歴・年代記は残す
- **未決定** 建物とともに土地の履歴もすべて削除
- **未決定** 廃村化した地域そのものをマップから消す

<a id="q5"></a>
### 5. 住居無償生成の経済的扱い

- **未決定・推奨** 住居はNPCに無償だが世界の資源・建設能力を消費する
- **未決定** 住居は資源も費用も消費せず無制限に生成
- **未決定** 住居は移住者が必ず代金を支払う

## 既存仕様との整合

- v4.9で移住直後の無償住居生成と廃村時の建物全削除を採用。
- v4.4の国家滅亡時の住民・施設・歴史保持は廃村化と区別する。
- 建築資源の消費はv4.9で未確定のため、v5.0で明示的に選択する。
