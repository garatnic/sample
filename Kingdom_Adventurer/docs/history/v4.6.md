## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。元の3択と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 国家の領土拡張速度

- **採用・確定** 人口・資金・行政力に応じて拡張速度を制限
- **不採用（再検討可）** 未所属地なら距離に関係なく即座に拡張
- **不採用（再検討可）** 国家は一定期間ごとに固定面積を獲得

<a id="q2"></a>
### 2. 未所属地への入植

- **採用・確定** NPCが移住・開拓し集落が形成されると国家支配が定着
- **不採用（再検討可）** 領有宣言だけで人口と施設が自動生成
- **不採用（再検討可）** 未所属地は領有できるがNPCは移住しない

<a id="q3"></a>
### 3. 国境地域の争い

- **採用・確定** 隣接国家の関係悪化や領有希望が戦争要因になる
- **不採用（再検討可）** 国境は完全に固定され領有争いは起こらない
- **不採用（再検討可）** 隣接するだけで定期的に戦争が起きる

<a id="q4"></a>
### 4. 国家指導者の個性

- **採用・確定** 性格・能力・経験・対人関係が判断に影響
- **不採用（再検討可）** 性格のみが外交・軍事・内政判断に影響
- **不採用（再検討可）** すべての指導者は同じ判断ルールを使う

<a id="q5"></a>
### 5. 歴史の閲覧方法

- **採用・確定** 世界全体・国家・人物ごとの年代記を検索・閲覧できる
- **不採用（再検討可）** 国家ごとの主要事件だけ一覧表示
- **不採用（再検討可）** 歴史は内部保存のみでプレイヤーは閲覧できない

## 既存仕様との整合

- v4.5の平和的領土拡張、地域単位の国境、指導者の性格・能力による自律判断、国家年代記を詳細化する。
- v4.2の開戦・反乱・独立の方針（外交関係が主な開戦条件、反乱・独立なし）を維持する。

## 確定内容の補足

- 未所属地の拡張速度は人口・資金・行政力に応じて制限。NPCの移住・開拓と集落形成によって支配が定着する。
- 国境の争いは関係悪化や領有希望によって戦争要因となる。隣接のみで自動開戦しない。
- 指導者の性格・能力・経験・対人関係が意思決定に影響する。
- 世界全体・国家・人物単位の年代記を検索・閲覧できる。v4.5の履歴保存方針を継承。
