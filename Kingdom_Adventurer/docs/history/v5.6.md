## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 家賃の支払い周期

- **採用・確定** ゲーム内の月ごとに家賃を支払い、契約内容に応じて更新する
- **不採用（再検討可）** 入居時に一度だけ家賃を支払う
- **不採用（再検討可）** 家賃の支払いをシミュレーションしない

<a id="q2"></a>
### 2. 家賃滞納時の扱い

- **不採用（再検討可）** 滞納が続くと交渉・猶予期間を経て退去や転居を検討する
- **不採用（再検討可）** 1回滞納した瞬間に強制退去
- **採用・確定** 滞納しても契約に影響しない

<a id="q3"></a>
### 3. 住宅売買の成立条件

- **採用・確定** 売主・買主双方の合意と支払能力が揃った場合に成立
- **不採用（再検討可）** 所有者の同意なしに購入できる
- **不採用（再検討可）** 売買価格だけ決まれば資金不足でも成立

<a id="q4"></a>
### 4. 複数住宅の賃貸管理

- **採用・確定** 所有者NPCが賃料・入居希望・空室を見て自律的に賃貸運用する
- **不採用（再検討可）** 複数所有した住宅は必ず空き家にする
- **不採用（再検討可）** すべての賃貸契約はプレイヤーが手動設定する

<a id="q5"></a>
### 5. 廃村化時の住宅所有権

- **採用・確定** 建物削除と同時に住宅の所有権は消滅し、土地と取引の履歴のみ残す
- **不採用（再検討可）** 建物削除後も存在しない住宅の所有権を永続保持
- **不採用（再検討可）** 廃村化しても住宅だけは削除せず残す

## 既存仕様との整合

- v5.5で変動家賃・市場に基づく売買価格・複数住宅所有と賃貸・住宅の完全非損壊を確定。
- v5.4で空き家の購入・賃貸・無償貸与には所有者の同意が必要と確定。
- v5.0で廃村化時に建物を削除するが地形・道路・土地履歴・年代記を残すと確定。

## 確定内容の補足

- 家賃はゲーム内の月ごとに支払い、契約内容に応じて更新する。
- **第2問は第3候補を採用**。家賃滞納は賃貸契約に影響せず、滞納による契約解除・強制退去は発生しない。未払い額の記録や回収方法は未決定。
- 住宅売買は売主・買主双方の合意と買主の支払能力が必要。
- 複数住宅を所有するNPCは賃料・入居希望・空室に基づき自律的に賃貸運用する。
- 廃村化で建物が削除されると住宅所有権も消滅し、土地と取引の履歴を保持する。
