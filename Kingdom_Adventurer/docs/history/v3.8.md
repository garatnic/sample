## 確認事項と選択肢

<a id="q1"></a>

### 1. 商品価格の決定方法

- **採用** 地域の需要・供給・在庫・輸送費で自動変動（既存仕様に準拠）
- **不採用** 基準価格を中心に小幅変動
- **不採用** 商品価格は基本固定

<a id="q2"></a>

### 2. NPCが商品を購入する判断

- **採用** 生活需要・所持金・価格・在庫に応じて購入（推奨）
- **不採用** 一定時間ごとに決まった商品を購入
- **不採用** ランダムに商品を購入

<a id="q3"></a>

### 3. NPCの商店経営

- **採用** 仕入れ・販売・雇用・開業・閉店を自律判断（既存仕様に準拠）
- **不採用** 既存店舗が仕入れと販売のみ自動実行
- **不採用** 店舗は固定で倒産・新規開業なし

<a id="q4"></a>

### 4. 貨幣システム

- **採用** 世界共通の単一通貨（推奨）
- **不採用** 国家ごとに異なる通貨と為替相場
- **不採用** 通貨と物々交換を併用

<a id="q5"></a>

### 5. 経済バランスの調整

- **採用** 極端な物価・資金不足を緩和する仕組みを設ける（推奨）
- **不採用** 補正なし。需給と資産移動だけで経済を動かす
- **不採用** 価格や収入を一定範囲に強く固定する

Kingdom Adventurer — 仕様案 v3.8

生産・物流仕様の確定／商店・市場・価格・貨幣・経済バランス

v3.7の5項目を確定仕様として整理する。

今回の決定で、農業・牧畜・製造は簡略化しつつ、資源の在庫や物流、NPCによる経済活動は維持する方針になった。

生産工程を必要以上に複雑にせず、世界全体の経済シミュレーションに処理能力を振り向けられる構成になる。

#### 1. v3.7で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 農業 | 農地が一定時間ごとに食料を自動生産 |
| 牧畜 | 牧場施設が一定時間ごとに畜産物を生産 |
| 採掘 | 鉱床ごとに採掘量と再生時間を設定し、継続採掘可能 |
| 製造 | 原材料から完成品を直接製造 |
| 物流 | 近距離は商隊・船が実際に移動し、遠距離は簡易シミュレーション |

既存仕様との整合

製造では中間製品の工程を必須とせず、原材料から直接完成品を作る。

例えば、鉄鉱石などの必要材料を揃えれば、鍛冶工房で剣を製造できる。

ただし、材料の在庫、職人の技能、製造時間、完成品の品質などは引き続き反映する。

また、農地や牧場は自動生産するが、生産物は実際の在庫として記録される。無条件に商店へ商品が出現するわけではない。

#### 2. 次のテーマ：商店・市場・価格・貨幣・経済バランス

Kingdom Adventurerの経済は、NPCが実際に働き、商品を売買し、お金を使って生活する仕組み。

既に以下の基本仕様が決まっている。

NPCは個別に所持金や財産を持つ。

商店は商品を仕入れ、在庫を持って販売する。

商品価格は地域の需要と供給によって変動する。

NPCは食料・衣服・道具などを購入する。

NPCが店舗を開業・経営・閉店できる。

通常の売買では、お金は売り手と買い手の間を移動する。

商隊や船が地域間の商品流通を支える。

今回は、経済が長期間にわたって自律的に動くためのルールを決める。

#### 3. 経済循環のイメージ

ある街の経済循環

農場

食料を生産

商店

仕入れ・販売

住民

働いて消費

領主・国家

税収・公共支出

商品・労働・貨幣がそれぞれの主体の間を循環する

例えば、ある街で食料が不足すると価格が上がり、商人が別の街から食料を運び込む。

その結果、供給が回復すれば価格が下がる。

こうした変化をNPCの自律的な行動から生み出すことが目標になる。

#### 4. v3.8で確定したい5項目

緩和策を選んでも、通常の取引でお金が無条件に発生するわけではない。

#### 5. 次の検討予定

v3.8の次は、国家財政・税金・公共事業・領地経営の詳細を検討する。

税率・税目の設定とNPCによる自動運営は既に決まっているため、次は税金の使い道、国家の支出、公共施設の建設、財政赤字への対応などを具体化する。

これによって、個人の経済活動から国家の財政までをつなげられる。
