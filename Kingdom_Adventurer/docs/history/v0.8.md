## 確認事項と選択肢

<a id="q1"></a>

### 1. 魔物の発生方法

- **不採用** 繁殖・移住・特殊発生源を基本（推奨）
- **不採用** 一定時間ごとにランダム出現
- **採用** 生態系＋補助的なランダム出現

<a id="q2"></a>

### 2. 魔物の巣

- **不採用** 自律的に成長・拡大・衰退（推奨）
- **採用** 固定配置・定期復活

<a id="q3"></a>

### 3. ダンジョン攻略後

- **採用** 攻略結果を保存し、時間経過で変化（推奨）
- **不採用** 一定期間で初期状態に戻る
- **不採用** 一部永続・一部リセット

<a id="q4"></a>

### 4. ボスの扱い

- **採用** 固有個体と通常の強敵が共存（推奨）
- **不採用** ボスは定期的に再出現
- **不採用** ボスは少数の固定イベントのみ

<a id="q5"></a>

### 5. 地域の危険度

- **採用** 地域の基本危険度＋強い個体が混在（推奨）
- **不採用** 地域ごとに明確な強さの段階
- **不採用** 地域に関係なく幅広い強さが出現

Kingdom Adventurer — 仕様案 v0.8

戦闘仕様の確定・魔物生態系とダンジョンの設計

今回の決定で、戦闘の基本方針が固まった。

特に重要なのは、プレイヤーのレベルに合わせて敵が強くなることはなく、世界の中で魔物自身が成長・繁殖・移動するという点。

これによって、序盤の森林でも強力な個体が現れたり、放置された魔物の巣が周辺の集落を脅かしたりする世界を目指せる。

#### 1. v0.7で確定した戦闘仕様

| 項目 | 確定内容 |
| --- | --- |
| 敵の強さ | 種族・環境・個体の成長で決定 |
| レベル連動 | プレイヤーレベルには連動しない |
| 難易度 | 適度な危険性。装備と育成が重要 |
| プレイヤー死亡 | 拠点で復活 |
| 死亡ペナルティ | 経験値と所持品の一部を失う |
| 仲間NPC | 永久死亡しない |
| 仲間AI | 詳細な戦闘方針を設定可能 |

プレイヤーの死亡ペナルティについて、失う経験値の割合やアイテムの扱いは未確定。

また、仲間NPCは永久死亡しないという仕様を優先する。一般NPCの永久死亡とは区別し、仲間が戦闘不能になった場合の復帰方法を後で設計する。

#### 2. 魔物も世界の住人として扱う

野生生物型

狼、熊など。縄張り、食料、繁殖を持つ。

集団生活型

ゴブリンなど。集落や巣を作り、集団で活動。

特殊発生型

アンデッドなど。呪われた土地や遺跡で発生。

強大な個体

ドラゴン、古代魔物など。広大な縄張りを持つ。

魔物は単純なランダム出現ではなく、可能な範囲で生息地や発生源を持たせる。

例えば狼の群れを討伐すると、その地域の狼の数が減少する。しかし、時間が経過すれば繁殖や周辺地域からの移動によって回復する。

#### 3. 魔物の巣と勢力拡大

例：ゴブリンの巣が成長する過程

この成長はプレイヤーが近くにいなくても進行する。

巣を破壊すれば魔物の供給源を断てるが、別の群れが移住してくる可能性もある。

#### 4. ダンジョンの役割

既に「固定ダンジョン＋自動生成ダンジョン」は確定している。

ここでは、ダンジョンを単なる戦闘エリアにせず、世界の一部として扱うことを提案したい。

古代遺跡

古い文明の建造物。特殊な装備、歴史資料、希少な素材が見つかる。

自然洞窟

鉱石や地下生物が存在。採掘や探索の対象になる。

魔物の巣

魔物が生活する拠点。討伐によって周辺地域の危険度が変化する。

地下墓地・封印施設

特殊な魔物や仕掛けが存在。世界の歴史や固定クエストとも関係する。

#### 5. 魔物とダンジョンで決めたい5項目

ここでは世界の変化、探索の繰り返しやすさ、強敵の存在を決める。

#### 6. 次の設計段階

魔物とダンジョンの仕様が確定したら、次は装備・アイテム・製作システムを設計したい。

既に装備のランダム性能・品質・特殊効果は確定しているので、次は武器種、防具、装備強化、耐久度、アイテムの流通、採集・製作を具体化する。

特に、魔物から得られる素材がNPCの経済活動にも使われる仕組みにすれば、冒険と世界シミュレーションを自然につなげられる。
