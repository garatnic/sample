## 確認事項と選択肢

<a id="q1"></a>
### 1. 兵士の募集・補充

- **採用・確定** 平時は志願兵を雇用し戦時には必要に応じ徴兵も実施
- **不採用（再検討可）** 志願兵の雇用のみで軍隊を編成
- **不採用（再検討可）** 国家が人口に応じて自動徴兵

<a id="q2"></a>
### 2. 軍隊の編成

- **不採用（再検討可）** 歩兵・弓兵・騎兵・魔法兵など役割別の部隊を編成
- **採用・確定** 兵士数と総合戦力のみで管理
- **不採用（再検討可）** 全兵士の装備・技能・所属を個別管理

<a id="q3"></a>
### 3. 開戦判断

- **不採用（再検討可）** 国益・外交関係・軍事力・財政・国境状況を総合判断
- **採用・確定** 外交関係の悪化を主な開戦条件とする
- **不採用（再検討可）** 一定確率で国家間戦争が発生

<a id="q4"></a>
### 4. 占領地の統治

- **不採用（再検討可）** 軍事占領後、治安・住民感情・統治体制を段階的に安定化
- **採用・確定** 占領すると即座に通常領地として統治
- **不採用（再検討可）** 占領地では必ず抵抗組織が発生し鎮圧が必要

<a id="q5"></a>
### 5. 和平交渉

- **採用・確定** 戦況・国力・財政・外交関係に応じて領土・賠償・停戦を交渉
- **不採用（再検討可）** 一方の国家が降伏するまで戦争を継続
- **不採用（再検討可）** 一定期間経過すると自動的に和平

## 確定仕様の補足

- 軍隊は兵士数と総合戦力で管理し、役割別の部隊編成や全兵士の個別装備管理は必須にしない。
- 開戦判断は外交関係の悪化が主条件。具体的な閾値や例外は未決定。
- 占領後は直ちに通常領地として統治する。段階的な占領統治は採用しない。
- 和平は戦況・国力・財政・外交関係に応じて交渉する。
- v3.9の実在する国庫・国家予算と整合させ、募集・軍維持に資金が必要となる詳細は今後検討する。
