# v4.9 移住後の生活・廃村復興・移住先選択・記録要約

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補を残し、不採用案も再検討可能。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 移住直後の住居確保

- **不採用（再検討可）** 空き家・宿泊施設・仮住まいを利用し、後から恒久住宅を確保
- **採用・確定** 移住した瞬間に新しい住居を無償生成
- **不採用（再検討可）** 住居が確保できなければ移住を取り消す

<a id="q2"></a>
### 2. 移住後の就職

- **採用・確定** 求人・技能・賃金を考慮して就職活動し、見つからなければ一時的に無職
- **不採用（再検討可）** 移住時に必ず最適な職業へ即時就職
- **不採用（再検討可）** 就職は国家がすべてのNPCに一律指定

<a id="q3"></a>
### 3. 廃村になった集落の扱い

- **不採用（再検討可）** 建物や道路は残存・劣化し、再入植で復興可能
- **採用・確定** 廃村になった瞬間に集落の建物を全削除
- **不採用（再検討可）** 廃村になっても建物は永久に劣化しない

<a id="q4"></a>
### 4. 移住先の選択

- **採用・確定** 生活条件の魅力に加え、距離・移動費・家族関係も考慮
- **不採用（再検討可）** 最も生活条件が良い集落へ必ず移住
- **不採用（再検討可）** 移住先はランダムに決定

<a id="q5"></a>
### 5. 日常記録の要約頻度

- **採用・確定** ゲーム内の一定期間ごとに要約し、重要な人物・地域は詳細度を高める
- **不採用（再検討可）** すべての記録を毎日一律に要約
- **不採用（再検討可）** 日常記録は保存せず、その場で破棄する

## 整合性と検討事項

- v4.8では住居・仕事がなくても移住でき、移住後に自動確保すると確定。確保にかかる時間や暫定状態を本版で検討する。
- v4.8では集落の縮小・廃村化、重要事件の永続保存、日常記録の期間要約を採用。

## 確定内容と整合性

- **第1問は第2候補を採用**。移住直後に住居を無償生成する。v4.8の「住居なしでも移住可能」と両立する。
- 移住後は求人・技能・賃金を考慮して求職し、見つからなければ一時的に無職になる。v4.8の「仕事を移住後に自動確保」は自律的な求職処理を指し、即時就職保証ではない。
- **第3問は第2候補を採用**。廃村化した瞬間に集落の建物を全削除する。v4.4の国家滅亡時の施設保持とは別のイベントであり、国家滅亡だけでは施設を削除しない。
- 移住先は生活条件・距離・移動費・家族関係を考慮する。
- 日常記録はゲーム内の一定期間ごとに要約し、重要人物・地域の記録粒度を高める。
