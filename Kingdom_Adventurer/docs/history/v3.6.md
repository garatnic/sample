## 確認事項と選択肢

<a id="q1"></a>

### 1. 野生動物の個体数

- **不採用** 繁殖・死亡・狩猟によって地域ごとの個体数が増減（推奨）
- **不採用** 一定時間ごとに決まった数が再出現
- **採用** 個体数はほぼ一定

<a id="q2"></a>

### 2. 食物連鎖・捕食関係

- **不採用** 捕食・餌不足を簡易計算し個体数に反映（推奨）
- **不採用** 個々の動物が狩り・捕食・食事を詳細に行う
- **採用** 食物連鎖は見た目の演出のみ

<a id="q3"></a>

### 3. 野生動物・魔物の生息地域

- **不採用** 環境・餌・危険・季節などに応じて変化（推奨）
- **採用** 種類ごとに決まった地域にのみ生息
- **不採用** 地域間をランダムに移動

<a id="q4"></a>

### 4. 採集資源の再生

- **採用** 木材・植物・鉱石などが条件と時間に応じて再生（推奨）
- **不採用** 植物は再生するが鉱石などは枯渇
- **不採用** 採集後すぐに再生し実質無制限

<a id="q5"></a>

### 5. 環境の長期変化

- **不採用** 伐採・開拓・災害・気候などで環境や生物分布が変化（推奨）
- **不採用** 建築・伐採など見た目の変化のみ
- **採用** 地域環境は基本的に変化しない

Kingdom Adventurer — 仕様案 v3.6

戦闘AI・難易度仕様の確定／魔物・野生動物・生態系・資源循環

v3.5の5項目を確定仕様として整理する。

今回の決定で、通常戦闘の操作負担を抑えつつ、必要な場面ではプレイヤーが介入できる戦闘システムが固まった。

#### 1. v3.5で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 攻撃対象 | 基本は自動選択。プレイヤーによる手動指定も可能 |
| スキル自動使用 | HP・MP・敵の状況などに応じた使用条件を設定可能 |
| 難易度調整 | 敵の能力値・攻撃力・耐久力などを調整。レベル連動なし |
| 撤退・降伏 | HP・戦力差・性格・状況を考慮して判断 |
| 敵集団の連携 | 前衛・後衛・支援などの役割に応じて連携 |

戦闘の基本方針

通常攻撃は自動で行い、スキルも条件付きで自動使用できるため、毎回すべての操作を手動で行う必要はない。

一方、強敵との戦闘では攻撃対象の指定や仲間の行動方針の変更によって、プレイヤーが戦術的に介入できる。

また、難易度を変更しても、敵がプレイヤーのレベルに合わせて自動的に強くなることはない。

#### 2. 次のテーマ：魔物・野生動物・生態系・資源循環

Kingdom Adventurerの世界には、人間や他種族のNPCだけでなく、魔物や野生動物も生息する。

これらが単に決まった場所に出現するだけなのか、それとも環境や時間によって変化するのかを決めたい。

既に次の仕様は確定している。

地域ごとに気候・地形・生態系が異なる。

魔物の巣は種類・環境・時間に応じて再出現する。

魔物の巣が自律的に無制限に拡散することはない。

ダンジョンは攻略後も新しい勢力に占拠される場合がある。

採集資源や宝箱は一定期間で再出現する。

魔物の討伐や巣の攻略は周辺地域の治安や経済に影響する。

今回は、生物の個体数、移動、資源の再生、環境変化について具体化する。

概念図。食物連鎖や資源再生をどこまで計算するかは未確定。

生態系を細かく再現すると世界の変化に説得力が出る一方、遠方の地域まで全生物を個別に計算すると処理負荷が大きくなる。

そのため、既存の遠景シミュレーション方式と組み合わせることを前提に、次の5項目を決める。

#### 4. v3.6で確定したい5項目

魔物の巣そのものが自律的に拡散しない既存仕様は維持する。

#### 5. 次の検討予定

v3.6の次は、農業・牧畜・採掘・生産・物流を詳しく検討する。

NPCの経済活動は既に基本仕様として確定しているため、次は生産に必要な時間・資材・土地、物流の処理方法、生産施設の自動運営などを具体化する。

これにより、自然環境から資源が採集され、加工・輸送・販売され、最終的にNPCの生活を支えるまでの流れを整理できる。
