## 決定事項

> Kingdom Adventurer v3.3のプレイヤー死亡・後継者・世代交代仕様として、寿命：種族ごとの寿命に従い加齢・老衰する。後継者：家族・子供・弟子・仲間などから自由に選択。財産と地位の継承：財産のみ継承し地位は失う。戦闘不能・死亡：拠点で復活し所持金のみ少額減少。後継者不在時：同じ世界で新しい冒険者を作成して継続。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. プレイヤーの寿命

- **採用** 種族ごとの寿命に従い加齢・老衰（既存仕様）
- **不採用** プレイヤーだけ寿命が大幅に長い
- **不採用** 設定で加齢・老衰を無効化できる

<a id="q2"></a>

### 2. 後継者の選択範囲

- **採用** 家族・子供・弟子・仲間などから自由に選択（既存仕様）
- **不採用** 血縁者のみ選択可能
- **不採用** 最適なNPCを自動選択

<a id="q3"></a>

### 3. 財産・地位の継承

- **不採用** 相続規則・組織規則・政治体制に従う（推奨）
- **不採用** 選択した後継者がすべて継承
- **採用** 財産のみ継承し地位は失う

<a id="q4"></a>

### 4. 戦闘で死亡した場合

- **不採用** 拠点で復活し、経験値・アイテムにペナルティ（既存仕様）
- **採用** 拠点で復活し、所持金のみ少額減少
- **不採用** 戦闘死でも世代交代が発生

<a id="q5"></a>

### 5. 後継者がいない場合

- **採用** 同じ世界で新しい冒険者を作成して継続（推奨）
- **不採用** 世界に存在するNPCから次の主人公を選ぶ
- **不採用** 後継者がいなければゲーム終了

## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

Kingdom Adventurer — 仕様案 v3.3

NPCの人生・世代交代仕様の確定／プレイヤーの死亡・後継者・継承

v3.2の5項目を確定仕様として整理する。

今回の決定では、NPCの職業・結婚・相続・技能習得には自律性を持たせながら、子供の成長は一定年齢で成人へ切り替える簡易方式になった。

これにより、世代交代の仕組みを維持しつつ、子供の成長段階ごとの複雑な処理を抑えられる。

#### 1. v3.2で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 職業変更 | 能力・希望・求人・経済状況に応じて自由に転職 |
| 子供の成長 | 一定年齢に達すると一気に成人 |
| 結婚・家庭 | 相性・友好度・生活条件を考慮して自律的に形成 |
| 財産相続 | 家族関係と相続規則に従って土地・建物・財産・事業を継承 |
| 技能継承 | 親・師匠・学校・仕事を通じて技能を習得 |

子供の成長について

子供は出生時から個別のNPCとして存在し、年齢や家族関係などを保持する。

ただし、幼児・少年・青年などの細かな成長段階は設けず、一定年齢で成人に切り替わる。

成人後は通常のNPCとして就職・結婚・冒険・経営などを行える。

成人年齢そのものは未確定とする。

#### 2. 次のテーマ：プレイヤーの死亡・後継者・世代交代

Kingdom Adventurerでは、プレイヤーも世界の住人の一人。

冒険を続けるうちに年齢を重ね、やがて寿命を迎える。

しかし、そこでゲームが終了するわけではない。後継者に操作を引き継ぎ、同じ世界で冒険を続ける。

これまでに確定している基本仕様は以下のとおり。

プレイヤーは加齢し、寿命によって死亡する。

死亡後は家族・子供・弟子・仲間などから後継者を選ぶ。

世界の地形・国家・歴史・NPCはそのまま継続する。

財産や地位は継承されるが、技能・レベルは後継者本人のものを使用する。

戦闘で死亡した場合は、拠点で復活し、経験値やアイテムにペナルティが発生する。

今回は、この基本仕様をさらに具体化する。

#### 3. 世代交代のイメージ

初代冒険者

冒険者として名声を得て、領地と財産を築く。

寿命による世代交代

二代目冒険者

初代の財産や拠点を引き継ぎ、自分の能力で新たな冒険を始める。

さらに世代交代

三代目冒険者

変化した世界を舞台に、家業を継ぐことも別の道を選ぶこともできる。

重要なのは、世代交代が単なるキャラクターの入れ替えではなく、これまでの行動が世界に残ったまま、新しい人生を始める仕組みになること。

#### 4. v3.3で確定したい5項目

#### 5. 次の検討予定

v3.3の次は、冒険者の成長・技能・職業・魔法の詳細仕様を検討する。

既にレベル制と技能熟練度制の併用は決まっているため、次は技能の種類、成長速度、職業の制限、魔法の習得方法などを具体化する。

これによって、世代交代後の新しい冒険者が、前の世代とは異なる育成方針で冒険できる仕組みを固めていく。
