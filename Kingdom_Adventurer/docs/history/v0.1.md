## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

では、半自動戦闘を採用して、ゲーム全体の仕様を組み立てよう。

今回のゲームは、単なる2D版スカイリムではなく、Kingdom Observerのように自律して動く世界を、一人の冒険者として自由に探索するRPGを目指す。

まずは仮称を「Kingdom Adventurer」としておこう。既存のKingdom Observerとは別ゲームとして設計する想定だよ。

Kingdom Adventurer — 基本構想 v0.1

#### 1. ゲームの全体構造

自律して変化する世界

国家・都市・村・経済・住民・魔物・戦争

プレイヤー

探索・戦闘・成長・交流

世界への干渉

討伐・交易・救援・戦争

基本原則は3つ。

プレイヤーが何もしなくても世界は動く。

プレイヤーの行動は世界に影響を与える。

世界はプレイヤーのレベルに合わせて不自然に変化しない。

#### 2. ゲームシステムの全体仕様案

| 分野 | 仕様案 |
| --- | --- |
| マップ | シームレスな広大な2D世界 |
| 地形 | 森林、平原、山岳、砂漠、湿地、海岸 |
| 集落 | 村、町、都市、王都が自律発展 |
| NPC | 個人ごとに職業、能力、所属、生活行動 |
| 国家 | 領土、外交、戦争、経済、軍隊 |
| 魔物 | 生息域、繁殖、移動、巣、襲撃 |
| 戦闘 | 半自動リアルタイム |
| 成長 | レベル＋スキル熟練度 |
| 装備 | 武器、防具、アクセサリー |
| アイテム | 採集、製作、交易、戦利品 |
| クエスト | 固定クエスト＋世界状況から自動生成 |
| 生活 | 宿泊、買い物、製作、住居 |
| 時間 | 昼夜、季節、経年変化 |
| 死亡 | ペナルティあり、ゲーム継続可能 |
| セーブ | 自動保存＋手動保存 |

これはまだ確定仕様ではなく、検討用の初期案。

#### 3. 半自動戦闘の具体的な仕組み

想定する操作は、移動と判断が主体。

敵に近づくと通常攻撃を自動で行う。

プレイヤーは自由に移動できる。

スキルや魔法は任意のタイミングで使用。

攻撃対象は自動選択、手動指定も可能。

HPが減ったら回復薬を使用。

逃走すれば戦闘から離脱できる。

敵も同じ世界の住人として行動する。弱い敵は逃げ、群れは協力し、強い魔物は縄張りを守る。

ただし、戦闘が単調にならないように、敵の種類や行動パターンには変化を持たせる。

#### 4. プレイヤーの成長システム

ここは自由度を重視して、職業を固定しない方式を提案したい。

スキル熟練度の表示イメージ。数値は仮。

例えば剣を使えば剣術が成長し、魔法を使えば魔法が成長する。さらに冒険者レベルによって基礎能力も上がる。

これなら剣士から魔法剣士、さらに商人や鍛冶職人へと自由に方向転換できる。

#### 5. 世界の自律シミュレーション

ここがゲームの中心になる。

村と都市

人口、食料、資金、治安に応じて発展する。住民が移住し、施設が建設される。

経済と交易

商人が町を行き来する。交易路が危険になると物資が不足し、価格が上がる。

国家と戦争

国家が領土を争い、軍隊が移動する。プレイヤーは傭兵として参加できる。

魔物の生態

魔物が繁殖し、巣を作り、周辺地域へ広がる。放置すれば集落を脅かす。

重要なのは、これらが独立した演出ではなく、相互に影響すること。

例えば魔物が増える → 商人が襲われる → 食料が不足する → 住民が移住する → 村が衰退する、という連鎖を実現したい。

#### 6. 世界の規模

広大な世界を実現するために、3段階のシミュレーションを提案する。

| 距離 | 処理方式 |
| --- | --- |
| プレイヤー周辺 | NPC・魔物を個別にリアルタイム処理 |
| 少し離れた地域 | 集団・集落単位で簡易処理 |
| 遠隔地域 | 経済・人口・戦争などを統計的に更新 |

この方式なら、世界に数千〜数万人の住民が存在しても、全員を常時画面上で動かす必要はない。

もちろん実現可能な規模は実装と端末性能によるので、最初から人数を確定する必要はない。

#### 7. 次に確定したい4つの仕様

ゲームの骨格を左右する項目をまとめた。私の初期推奨を選択しているけれど、自由に変更できる。

この4つが決まれば、次は「マップの構造」「NPCのAI」「戦闘と敵の強さ」「経済・アイテム・装備」「プレイヤーが世界に与えられる影響」をさらに具体化できる。

特に、既存のKingdom Observerとどの程度シミュレーション基盤を共有するかは、仕様が固まった段階で検討する価値がある。
