## 決定事項

> Kingdom Adventurer v3.4のキャラクター成長・技能・職業・魔法仕様として、職業：固定職業なし。技能の組み合わせで自由に育成。レベルと技能：レベルで基礎能力が成長し技能熟練度で専門能力が向上。技能の習得制限：すべての技能を習得・成長可能。魔法の習得：魔法書・教師・研究・実践などで習得。成長速度：初期は伸びやすく高熟練度ほど成長が緩やかになる。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 職業システム

- **採用** 固定職業なし。技能の組み合わせで自由育成（推奨）
- **不採用** 職業を選択し、専用技能を習得
- **不採用** 職業は存在するが技能習得を制限しない

<a id="q2"></a>

### 2. レベルと技能の役割

- **採用** レベルで基礎能力、熟練度で専門能力が成長（推奨）
- **不採用** レベルは目安で、強さは技能熟練度中心
- **不採用** レベルによる成長が中心

<a id="q3"></a>

### 3. 技能の習得制限

- **採用** すべての技能を習得・成長可能（推奨）
- **不採用** 習得可能な技能数に上限あり
- **不採用** 一部の技能は排他的で同時習得不可

<a id="q4"></a>

### 4. 魔法の習得方法

- **採用** 魔法書・教師・研究・実践などで習得（推奨）
- **不採用** レベル上昇時に自動習得
- **不採用** 商店で購入するだけで習得

<a id="q5"></a>

### 5. 技能の成長速度

- **採用** 初期は伸びやすく、高熟練度ほど成長が緩やか（推奨）
- **不採用** 熟練度にかかわらず一定速度
- **不採用** 短時間で多くの技能を最大まで育成可能

Kingdom Adventurer — 仕様案 v3.4

死亡・世代交代仕様の確定／キャラクター成長・技能・職業・魔法

v3.3の5項目を確定仕様として整理する。

今回の決定によって、プレイヤーは寿命によって世代交代する一方、戦闘で死亡しても比較的軽いペナルティで冒険を続けられる設計になった。

また、後継者は財産を引き継ぐものの、前任者の社会的地位までは自動的に継承しない。

#### 1. v3.3で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 寿命 | 種族ごとの寿命に従って加齢・老衰 |
| 後継者 | 家族・子供・弟子・仲間などから自由に選択 |
| 財産・地位 | 財産は継承するが、地位は失う |
| 戦闘死亡 | 拠点で復活し、所持金のみ少額減少 |
| 後継者不在 | 同じ世界で新しい冒険者を作成して継続 |

世代交代時の扱い

例えば、初代冒険者が国王だった場合、後継者は財産を相続できるが、国王の地位を自動的には引き継がない。

国家の新しい指導者は、その国家の政治体制や継承制度によって決まる。

また、後継者は自分自身のレベル・技能・経験を使用する。前任者の能力値をそのままコピーすることはない。

補足： 財産の相続と国家・組織の役職継承を別々に扱うことで、NPCの相続制度とも整合させる。

#### 2. 次のテーマ：キャラクター成長・技能・職業・魔法

これまでに確定している基本仕様は以下のとおり。

キャラクターレベルと個別技能の熟練度を併用する。

技能は実際の使用・訓練・教育によって成長する。

装備に厳しい能力条件はなく、技能や能力によって性能が変化する。

攻撃・回復・強化・召喚・生活補助などの魔法が存在する。

魔法はMPを消費し、MPは時間経過で回復する。

敵の強さはプレイヤーレベルに連動しない。

NPCや魔物も経験を積んで成長する。

今回は、どのように強くなり、どれだけ自由に育成できるかを決める。

#### 3. キャラクター育成のイメージ

同じ冒険者でも育成によって役割が変わる

剣士型

剣術・防御・体力を重点的に成長

魔法使い型

攻撃魔法・回復魔法・召喚を重点的に成長

探索者型

弓術・探索・採集を重点的に成長

職人型

鍛冶・錬金術・商業を重点的に成長

育成例であり、これらの職業区分が確定したわけではない。

このゲームでは、戦闘だけでなく、製造・採集・交易・建築なども重要な活動になる。

そのため、戦闘能力に偏らず、生活技能や生産技能にも成長の意味を持たせる必要がある。
