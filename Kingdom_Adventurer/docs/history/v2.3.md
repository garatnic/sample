## 当時の要件・懸念・検討の経緯

Kingdom Adventurer — 仕様案 v2.3

経済・交易仕様の確定／戦闘・魔法・キャラクター成長の詳細設計

v2.2の5項目を確定仕様として追加する。

これで、Kingdom Adventurerの経済は、実際に存在する商品・資源・貨幣が、NPCや商店、国家の間を移動する仕組みとして確定した。

次は、冒険者としての成長と戦闘の仕組みを詳しく決めよう。

#### 1. v2.2で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 生産 | 原材料・加工品・完成品を実在アイテムとして管理 |
| 生活需要 | 食料・住居・衣服・道具・娯楽など |
| 交易 | 商隊・船が実際に商品を運搬 |
| 店舗経営 | NPCが開業・雇用・仕入れ・販売・廃業を自律判断 |
| 貨幣 | NPC・商店・国家間で実際に移転 |

ここでの「実在アイテム」は、必ずしも全商品を個別の3D・2Dオブジェクトとして常時描画する意味ではない。

例えば、遠方の倉庫に鉄鉱石が500個ある場合、在庫データとして500個を保持し、輸送や消費によって数量を変更する。

ただし、帳簿上だけで無制限に商品が増えることはない。

また、貨幣については、通常の売買では必ず支払者から受取者へ移転する。採掘による貨幣の発行など、世界に貨幣が新たに供給される仕組みは今後の詳細設計事項とする。

#### 2. 次のテーマ：戦闘とキャラクター成長

これまでに確定している戦闘の基本方針は次のとおり。

通常攻撃は自動。スキルは手動・自動を切り替えられる。

敵の強さは種族・環境・個体の成長で決まり、プレイヤーレベルには連動しない。

装備と訓練によって強くなる。

プレイヤーは戦闘不能時に拠点で復活し、経験値と所持品にペナルティがある。

仲間には詳細なAI指示を設定できる。

職業は固定せず、自由に技能を成長させられる。

装備に耐久度はない。

今回は、この基本方針を変えずに、具体的な成長方式と戦闘の仕組みを決める。

#### 3. 成長システムの構想

キャラクターの成長例

剣術

剣で戦うほど熟練度が上昇

魔法

魔法の使用・研究で成長

鍛冶

製作経験によって品質が向上

交渉

交渉・取引によって熟練

例えば剣術に特化した冒険者でも、途中から鍛冶師や魔法使いとして成長できる。

また、仲間のNPCも同じ成長システムを使うことが確定しているため、長年一緒に冒険した仲間は自然に強くなっていく。

#### 4. 魔法システムの構想

攻撃魔法

火炎・氷結・雷撃など

回復・補助魔法

治癒・強化・防御など

召喚魔法

召喚獣・使い魔など

生活・探索魔法

照明・移動・探索補助など

これらは魔法の種類の例であり、まだ正式な魔法体系ではない。

#### 5. v2.3で確定したい5項目

#### 6. 次に検討すること

今回の成長・魔法仕様が確定したら、次は戦闘AI・敵の行動・戦闘バランスを詳しく検討する。

特に、敵がプレイヤーのレベルに連動しない世界では、序盤から危険な敵に遭遇する可能性がある。

その一方で、成長後も低レベル地域を探索する意味が残るように、戦闘以外の資源・交易・クエスト・人間関係などを充実させる必要がある。

この方針を維持しながら、難しすぎず、単調にもならない戦闘システムを設計していこう。
