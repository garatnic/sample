### 1. NPCの職業変更

- **採用** 能力・希望・求人・経済状況に応じて自由に転職（推奨）
- **不採用** 特別なイベント時のみ転職
- **不採用** 基本的に生涯同じ職業

<a id="q2"></a>

### 2. 子供の成長

- **不採用** 段階的に成長し、生活・学習・就労が変化（推奨）
- **採用** 一定年齢で一気に成人
- **不採用** 外見のみ成長し、能力や行動は変化しない

<a id="q3"></a>

### 3. 結婚・家庭形成

- **採用** 相性・友好度・生活条件を考慮して自律的に結婚（推奨）
- **不採用** 友好度のみで結婚を判断
- **不採用** ランダムイベント中心で結婚

<a id="q4"></a>

### 4. 死亡時の財産相続

- **採用** 家族関係と相続規則に従って継承（推奨）
- **不採用** 指定された後継者がすべて相続
- **不採用** 財産は消滅・再配分される

<a id="q5"></a>

### 5. 次世代への技能継承

- **採用** 親・師匠・学校・仕事を通じて学習（推奨）
- **不採用** 親の技能値の一部を生まれつき継承
- **不採用** 親や教育環境とは無関係に成長

Kingdom Adventurer — 仕様案 v3.2

ギルド・組織・雇用仕様の確定／NPCの生活・職業・家族・世代交代

v3.1の5項目を確定仕様として整理する。

今回の決定で、ギルドや組織はNPC自身が設立・発展させ、プレイヤーも自由に参加・設立できる仕組みになった。一方、雇用は細かな契約交渉を省き、定額制で扱う。

#### 1. v3.1で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 組織の自律性 | NPCが組織を設立・運営・拡大・解散できる |
| 組織への加入 | 複数組織に所属可能。ただし対立関係や組織規則による制約あり |
| プレイヤーの組織設立 | 資金・人員・拠点などの条件を満たせば自由に設立 |
| 雇用契約 | 定額の雇用費用を支払う簡易方式 |
| 仲間の自律行動 | 仲間ごとに戦闘・探索・回復・撤退などの方針を設定可能 |

雇用についての整理

雇用は、賃金・期間・待遇を個別に細かく交渉する方式ではなく、定額の雇用費用を支払う方式とする。

ただし、支払いが一度きりなのか、一定期間ごとなのかはまだ決めていない。仲間の人数に上限を設けないという既存仕様も維持する。

#### 2. 次のテーマ：NPCの生活・職業・家族・世代交代

このゲームでは、NPCが単に街を歩くだけではなく、生まれ、働き、家庭を築き、年老いて亡くなっていく。

そして、その子供たちが次の世代の社会を作る。

既に、NPCの出生・成長・結婚・死亡、職業、家族関係、財産、個人の能力、世代交代は基本仕様として確定している。

今回は、人生の途中で何が変化するのか、親から子へ何を引き継ぐのかを詳しく決める。

#### 3. NPCの人生のイメージ

あるNPCの一生（例）

幼少期農家の子供として生まれ、家族と暮らす。

青年期鍛冶師に弟子入りし、製作技能を習得する。

成人期独立して工房を開き、結婚して家庭を持つ。

壮年期商売が成功し、従業員を雇い、工房を拡大する。

老年期子供に技術を教え、家業を引き継がせる。

死後財産や工房が相続され、次の世代も生活を続ける。

人生の一例。NPC全員が同じ経歴をたどるわけではない。

重要なのは、NPCが最初に割り当てられた職業を一生続ける必要があるのか、家族や財産の相続をどこまで再現するのかという点。

#### 4. v3.2で確定したい5項目

#### 5. 今後の検討予定

v3.2の次は、プレイヤー自身の人生・死亡・後継者・世代交代を詳しく検討する。

NPCとプレイヤーが同じ世界の住人である以上、プレイヤーだけが特別な寿命や相続ルールを持つのか、それとも共通の仕組みにするのかが重要になる。

特に、プレイヤーの死後に誰を操作するか、財産・組織・地位・技能がどこまで引き継がれるかを決めることで、何世代にもわたって遊べるゲームの基盤が固まる。
