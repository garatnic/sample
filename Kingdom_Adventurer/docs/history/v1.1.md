## 決定事項

> Kingdom Adventurer v1.1の建築・拠点・領地経営仕様として、建築：土地条件を満たせば自由配置。土地所有：未所有地は自由に占有可能。集落発展：NPCが自律的に建築・移住・発展。領地管理：NPCに委任でき、直接管理も可能。建築物：損傷・破壊・修復あり。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 建築物の配置

- **採用** 土地条件を満たせば自由配置（推奨）
- **不採用** 区画・マス単位で配置
- **不採用** 建築候補地にのみ配置

<a id="q2"></a>

### 2. 土地の所有権

- **不採用** 国家・領主の所有権や法律に従う（推奨）
- **不採用** 資金があれば自由購入
- **採用** 未所有地は自由に占有可能

<a id="q3"></a>

### 3. 集落の自律発展

- **採用** NPCが自律的に建築・移住・発展（推奨）
- **不採用** プレイヤーが建築を指示
- **不採用** 自律発展と手動指示を併用

<a id="q4"></a>

### 4. 領地の管理方法

- **採用** NPCに委任＋直接管理も可能（推奨）
- **不採用** すべて手動管理
- **不採用** 基本すべて自動管理

<a id="q5"></a>

### 5. 建築物の損傷・破壊

- **採用** 損傷・破壊・修復あり（推奨）
- **不採用** 建築物は破壊されない
- **不採用** 戦争など特定条件でのみ破壊

Kingdom Adventurer — 仕様案 v1.1

仲間NPC仕様の確定／建築・拠点・領地経営システムの設計

今回の決定で、仲間NPCの基本仕様が確定した。

特に重要なのは、同行人数に上限を設けないこと。一人旅から始めて、数人の冒険者集団、さらに大規模な傭兵団へと発展させることも可能になる。

ただし、人数が増えても全員を常時詳細処理するのではなく、遠方や画面外の仲間には簡易処理を適用する設計が必要になる。

#### 1. v1.0で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 同行人数 | 人数制限なし |
| 加入方法 | 傭兵・友情・クエスト・家族など |
| 操作 | AI自律行動＋詳細な指示 |
| 成長 | プレイヤーと同じレベル・熟練度 |
| 死亡保護 | 同行・雇用中のみ永久死亡しない |

死亡保護は、契約や同行状態が終了した時点で解除される。

また、同行人数の無制限はゲームルール上の仕様であり、実際の描画・処理負荷への対策は別途設計する。

#### 2. 建築・拠点・領地経営の全体像

既に確定しているのは、土地購入、建築、拠点設立、店舗・工房経営、NPC雇用、領主への出世と領地経営。

これらを独立したシステムにせず、一つの土地・所有権・経済システムでつなげることを提案する。

例えば、土地を購入して家を建て、その隣に鍛冶工房を作る。NPCを雇って製作を任せ、商品を販売する。

さらに周囲の土地を取得して集落を発展させれば、領地経営へとつながる。

#### 3. 建築システム

住居

自宅、倉庫、家具、生活設備

生産施設

鍛冶場、農場、製材所、工房

商業施設

店舗、市場、宿屋、交易所

防衛施設

城壁、見張り塔、兵舎、城

建築物には所有者、耐久状態、材料、用途、維持費などの情報を持たせる案。

なお、装備の耐久度は「なし」で確定しているが、建築物の損傷・修理は別の仕様として検討できる。

#### 4. 拠点の発展

これは発展の一例であり、必ず順番に進む必要はない。

冒険者として活動しながら小さな家だけを持つこともできるし、商人として複数の町に店舗を所有することもできる。

#### 5. 領地経営

領主になった場合、以下の要素を管理できるようにする案。

| 分野 | 管理内容 |
| --- | --- |
| 人口 | 移住、出生、死亡、労働力 |
| 経済 | 生産、交易、税収、支出 |
| 建設 | 道路、住宅、施設、防衛設備 |
| 治安 | 衛兵、犯罪、魔物への対策 |
| 軍事 | 兵士の雇用、装備、領地防衛 |
| 外交 | 所属国家、他領主との関係 |

ただし、プレイヤーがすべてを手動管理する必要はない。

NPCに管理を委任し、プレイヤーは冒険を続けられる方式が、このゲームには適していると思う。

#### 6. 次に確定したい5項目

#### 7. 次の検討事項

建築と領地経営の仕様が決まれば、次は国家・外交・戦争の詳細に進みたい。

その後は、犯罪・法律・評判、クエスト、UI・操作、セーブと時間経過を整理する。

そして全仕様を統合し、矛盾や未決定事項を確認したうえで、開発ロードマップに落とし込む。

特に今回のゲームでは、一人の冒険者として自由に行動できることを優先し、領地経営などは必要に応じてNPCへ委任できるという考え方を一貫させたい。
