# v5.8 家賃負債相続・利息・支払優先・所有者変更・収益履歴

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 家賃負債の相続

- **採用・確定** 借主が死亡した場合、未払い家賃は相続財産とともに相続順位に応じて扱う
- **不採用（再検討可）** 借主死亡時に家賃負債を無条件で帳消しにする
- **不採用（再検討可）** 家賃負債は死亡後も故人名義で永久に増え続ける

<a id="q2"></a>
### 2. 家賃負債の利息

- **採用・確定** 未払い家賃に利息は付けず、元本のみを記録する
- **不採用（再検討可）** 未払い家賃に毎月一定の利息を加算する
- **不採用（再検討可）** 未払い家賃は毎月倍増する

<a id="q3"></a>
### 3. 家賃の自動支払い優先度

- **採用・確定** 生活必需費を確保したうえで余裕資金から当月家賃を支払う
- **不採用（再検討可）** 食料を買えなくなっても家賃を最優先で支払う
- **不採用（再検討可）** 所持金があっても家賃を一切支払わない

<a id="q4"></a>
### 4. 所有者変更時の賃貸契約

- **採用・確定** 住宅売買・相続で所有者が変わっても既存の賃貸契約を引き継ぐ
- **不採用（再検討可）** 所有者変更時に入居者を即時退去させる
- **不採用（再検討可）** 所有者が変わると住宅を削除して新築する

<a id="q5"></a>
### 5. 賃貸収益の記録

- **採用・確定** NPCの収支・資産履歴に家賃収入と滞納額を区別して記録する
- **不採用（再検討可）** 収益は残高にだけ加算し履歴を残さない
- **不採用（再検討可）** すべての賃貸収益を国家の収入として記録する

## 既存仕様との整合

- v5.7で家賃滞納は負債として記録するが契約継続・居住には影響しないと確定。
- v5.7で任意返済・分割払い、契約終了時の履歴保持、賃貸収益の生活・消費・投資への使用を確定。
- v5.4で住宅は親族関係と相続順位に従って相続し、v5.6で家賃は月払いと確定。

## 確定内容の補足

- 借主死亡時の家賃負債は相続財産とともに相続順位に応じて扱う。
- 未払い家賃は無利息で元本のみを記録する。
- 当月家賃の自動支払いは生活必需費を確保したうえで余裕資金から行う。未払い分はv5.7に従って負債として記録し、居住権に影響しない。
- 住宅の売買・相続で所有者が変わっても既存の賃貸契約を引き継ぐ。
- NPCの収支・資産履歴では受領した家賃収入と滞納額を区別して記録する。
