## 決定事項

> Kingdom Adventurer v1.8の寿命・世代交代・セーブ仕様として、寿命後：後継者を選んで同じ世界を継続。後継者：子供・家族・弟子・仲間などから選択。継承：財産・地位は相続し能力は後継者自身のもの。セーブ：オートセーブ＋手動セーブ。世界の継続：世代交代しても世界の状態と歴史をすべて維持。これらを確定仕様として整理し、次の未確定事項を検討したい。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 主人公が寿命を迎えた後

- **採用** 後継者を選び、同じ世界を継続（推奨）
- **不採用** 新しい人物を作成し、同じ世界を継続
- **不採用** 主人公の寿命でゲーム終了

<a id="q2"></a>

### 2. 後継者の候補

- **採用** 子供・家族・弟子・仲間など（推奨）
- **不採用** 血縁者のみ
- **不採用** 世界の任意のNPC

<a id="q3"></a>

### 3. 継承するもの

- **採用** 財産・地位を相続、能力は後継者自身（推奨）
- **不採用** 財産・地位・能力をすべて継承
- **不採用** 財産の一部のみ継承

<a id="q4"></a>

### 4. セーブ方式

- **採用** オートセーブ＋手動セーブ（推奨）
- **不採用** オートセーブのみ
- **不採用** 手動セーブのみ

<a id="q5"></a>

### 5. 世代交代後の世界

- **採用** 世界の状態・歴史をすべて維持（推奨）
- **不採用** 世界の一部を再生成

Kingdom Adventurer — 仕様案 v1.8

キャラクター作成仕様の確定／寿命・世代交代・セーブシステムの設計

v1.7の5項目を確定仕様として追加する。

今回の決定で特に重要なのは、主人公もNPCと同じく年齢を重ね、寿命を迎えること。

これまでの仕様と組み合わせると、主人公が亡くなっても世界そのものは存続し、家族や仲間、国家、建築物などが歴史として残るゲームを設計できる。

ただし、主人公の死後にどうするかは、まだ決まっていない。

#### 1. v1.7で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 外見 | 髪型・顔・体格・服装など詳細に変更 |
| 種族 | 人間・エルフ・ドワーフなど複数 |
| 出身・経歴 | 初期能力・人間関係・所持品に影響 |
| 開始地点 | 生成世界の複数候補から選択 |
| 主人公の加齢 | NPCと同じく加齢・寿命あり |

なお、種族ごとの寿命、能力差、文化、NPCとの関係については未確定。

#### 2. 主人公の寿命と世界の継続

想定する世代交代の例

初代主人公

冒険者として活動し、家を建て、家族を持つ。

二代目主人公

初代の子供が家や財産を受け継ぎ、冒険を続ける。

三代目主人公

祖先が築いた国家の歴史を引き継ぎながら、新しい人生を歩む。

世代交代のイメージ。後継者の選び方は未確定。

重要なのは、プレイヤーの操作キャラクターが変わっても、世界を初期化しないこと。

家族や仲間との関係、国家の歴史、建築物、経済状況はそのまま引き継ぐ。

#### 3. 戦闘不能と寿命による死亡は区別する

既に確定している仕様では、戦闘でHPがゼロになると拠点で復活し、経験値と所持品を失う。

一方、主人公には寿命がある。

この2つを両立するため、次の区別を提案する。

| 状態 | 結果 |
| --- | --- |
| 戦闘でHPがゼロ | 拠点で復活しペナルティを受ける |
| 老衰・寿命 | 主人公の人生が終了する |
| 寿命後 | 後継者へ引き継ぐか、新しい人物で続行 |

これなら通常の戦闘で冒険が突然終わることを避けつつ、世代交代をゲームの中心的な要素にできる。

#### 4. セーブと世界の永続性

世界には数千人のNPC、国家、建物、所有物、歴史などが存在する。

そのため、単にプレイヤーの位置やレベルだけでなく、世界全体の状態を保存する必要がある。

セーブデータの構造案

PC・スマホ両対応なので、セーブデータの容量や読み込み速度も重要になる。

#### 5. v1.8で確定したい5項目

#### 6. 次の設計段階

寿命と世代交代が確定したら、次は世界生成の詳細に進みたい。

地形、気候、国家の配置、都市数、種族分布、資源、魔物の生息域などをどう生成するかを検討する。

その後、ゲームバランスと技術仕様を整理し、全体の仕様を統合する。

特に、世代交代を繰り返して数百年、数千年と世界が続いても破綻しないことを、技術設計の重要な目標にする必要がある。
