Kingdom Adventurer — 仕様案 v1.3

国家・外交・戦争仕様の確定／犯罪・法律・評判システムの設計

v1.2の国家・外交・戦争に関する5項目を、確定仕様として整理した。

これにより、Kingdom Adventurerでは国家そのものが世代を超えて変化し、プレイヤーは一人の冒険者から独立国家の君主にまで成長できる設計になる。

#### 1. v1.2で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 国家の変化 | 成立・滅亡・分裂・統合が発生 |
| 戦争 | 宣戦・侵攻・包囲・占領・和平まで自律進行 |
| プレイヤーの建国 | 独立国家を建国可能 |
| 軍隊指揮 | 直接指揮とNPCへの委任の両方 |
| 政治 | 法律・税制・外交・継承・反乱などを詳細に扱う |

これまでの確定仕様とも整合している。

例えば、プレイヤーが建国した後に冒険へ出かけても、委任されたNPCが国政を進め、周辺国家が外交や戦争を続ける。

また、プレイヤーが何もしなくても、NPC国家が滅亡したり、新しい国家が成立したりする。

#### 2. 次のテーマ：犯罪・法律・評判

このシステムの目的は、プレイヤーの行動に社会的な意味を持たせること。

例えば、商人から商品を盗めば、その商人との関係が悪化する。目撃されれば衛兵が捜査し、犯罪として扱われる可能性がある。

一方、犯罪者を捕まえたり、盗賊から村を守ったりすれば、その地域での評判が上がる。

重要なのは、善悪を一つの数値だけで管理しないこと。

評判を複数の単位で管理する案

この方式なら、ある国家では英雄でも、敵対国家では危険人物として扱われることがある。

#### 3. 犯罪と法律

窃盗・侵入

所有物の持ち去りや立入禁止区域への侵入

暴行・殺人

被害者、目撃者、所属勢力によって反応が変化

略奪・密輸

交易や国家の法律に関係する犯罪

反逆・政治犯罪

国家への反乱、敵国への協力など

国家ごとに法律が異なる仕組みを採用すれば、同じ行動でも国によって合法・違法が変わる。

例えば、ある国では特定の魔法が禁止されていても、別の国では自由に使用できる、といった違いを表現できる。

#### 4. 犯罪発覚から処罰までの流れ

この流れはあくまで提案であり、すべての犯罪が必ず発覚するわけではない。

また、NPC同士の犯罪も同じ仕組みで扱うことで、衛兵がNPCの盗賊を追跡したり、NPCが投獄されたりする世界にできる。

#### 5. v1.3で確定したい5項目

#### 6. 次の設計段階

犯罪・法律・評判の仕様が決まれば、次はクエストと世界イベントを検討する。

特に、NPCの人生や国家間戦争から自然に発生する依頼をどう作るかが重要になる。

例えば、実際に食料不足に陥った村から食料調達の依頼が発生したり、行方不明になったNPCの家族が捜索を依頼したりする。

世界で起きた出来事がクエストになり、クエストの結果が再び世界に影響する仕組みを目指したい。
