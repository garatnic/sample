> Kingdom Adventurer v0.5のプレイヤー介入仕様として、住居・建築：土地購入・建築・拠点設立まで可能。商売：店や工房を経営しNPCを雇用可能。国家：領主になり領地経営まで可能。NPC交流：雇用・友情・恋愛・結婚など深い交流。クエスト：世界の状況から自動生成＋固定クエスト。この選択を確定仕様として整理し、次の未確定事項を検討しよう。

## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

では、Kingdom Adventurer 仕様案 v0.5 として、これまでの決定を整理しよう。

今回の決定によって、このゲームは一般的なオープンワールドRPGよりも、かなり生活シミュレーション寄りの世界を持つことになる。

ただし、主役はあくまで一人の冒険者。NPCの生活や経済は、プレイヤーが冒険する世界に意味を持たせるための仕組みとして設計する。

#### 1. v0.4で確定した仕様

| 分野 | 確定内容 |
| --- | --- |
| 職業・居住 | NPCが自律的に転職・独立・移住 |
| 経済 | NPCの生産・消費・交易を計算 |
| 人間関係 | 友情・恋愛・対立・協力が動的に変化 |
| 歴史 | NPC個人と世界の重要な出来事を記録 |
| 時間操作 | 宿泊・待機・長期間の時間経過が可能 |

これまでの確定仕様もすべて維持する。

#### 2. 世界シミュレーションの基本設計

ここで重要なのは、NPCの個別行動と世界全体の計算を同じ仕組みで扱うこと。

例えば、鍛冶師が鉄鉱石を購入して剣を製作する場合。

これを単なる演出ではなく、在庫や資金が実際に移動する仕組みにする。

鉱山が閉鎖されれば鉄鉱石が不足し、鍛冶師が剣を作れなくなる。商人が新しい交易路を開けば供給が回復する。

プレイヤーも、この経済活動に参加できる。

#### 3. NPCの処理をどう成立させるか

全NPCが個人情報を持ち、生活し、家族を作り、経済活動を行うことは確定した。

しかし、数千人を毎秒詳細に処理するのは非効率。

そこで次の方式を推奨する。

| 処理 | 近距離 | 遠距離 |
| --- | --- | --- |
| NPC移動 | 実際に歩く | 移動予定と到着時刻を計算 |
| 生産 | 作業アニメーション＋生産 | 生産量をまとめて計算 |
| 消費 | 食事・買い物行動 | 所持品・資金を更新 |
| 人間関係 | 会話や交流 | 関係変化を定期計算 |
| 戦闘 | 個別リアルタイム | 戦力・状況に応じて解決 |
| 出生・死亡 | 個別イベント | 個人単位で判定 |

重要なのは、近距離と遠距離で結果が矛盾しないこと。

例えば、遠方で死亡したNPCが、プレイヤーが近づいた途端に生き返るようなことは起こさない。

また、遠隔地で作られた商品も、実際の在庫として保存する。

#### 4. プレイヤーの介入

プレイヤーが世界に関与できる方法も考えておきたい。

経済への介入

商品売買、交易、工房経営、投資

NPCへの介入

雇用、護衛、救助、説得、依頼

国家への介入

傭兵、軍への参加、領主への協力

集落への介入

資材供給、施設建設、村の防衛

ここから先は、プレイヤーにどこまで自由を与えるかが重要になる。

例えば、商人として生活するだけでなく、工房を経営してNPCを雇ったり、土地を購入して村を作ったりできるようにするかどうか。

#### 5. 次に決めたい5つの仕様

今回はプレイヤーが世界とどう関わるかを決めたい。

ここで5項目すべてを最大自由度にすると、冒険者RPGに加えて建築ゲーム、経営ゲーム、国家運営ゲームの要素まで入る。

実装規模は大きくなるけれど、世界シミュレーションを共通基盤にできれば、それぞれを独立したゲームとして作るより統合しやすい。

次はこれらの選択を踏まえ、冒険者としての探索・戦闘・装備・ダンジョンの設計に進みたい。
