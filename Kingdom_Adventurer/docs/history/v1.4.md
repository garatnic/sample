## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

Kingdom Adventurer — 仕様案 v1.4

犯罪・法律・評判仕様の確定／クエスト・世界イベントの設計

v1.3の5項目を確定仕様に追加する。

今回は法律を世界共通にする一方、評判や犯罪の影響は地域・国家・組織ごとに異なるという設計になった。

これにより、複雑すぎる法体系を避けながら、社会シミュレーションの深さを維持できる。

#### 1. v1.3で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 犯罪発覚 | 目撃・証拠・通報によって発覚 |
| 法律 | 世界共通の法律 |
| 評判 | 個人・集落・国家・組織ごとに管理 |
| 処罰 | 罰金・投獄・追放・恩赦など |
| NPC犯罪 | NPCも自律的に犯罪・捜査・逮捕を行う |

世界共通の法律とは、何が犯罪になるかという基本ルールを共通化すること。

ただし、各国家の治安状況や衛兵の能力によって、捜査や逮捕の成功率が異なることは考えられる。

また、国家システムで確定した「詳細な政治・法律管理」との整合性を取るため、法律の種類は共通としつつ、国家による運用の違いをどこまで許すかは後で整理する。

#### 2. クエストの基本構造

既に確定しているのは、固定クエストと世界の状況に応じて自動生成されるクエストの併用。

今回検討したいのは、NPCや国家が本当に困っていることからクエストが生まれる仕組み。

例えば、村の食料が不足したときに食料調達の依頼が発生し、実際に食料を届ければ村の備蓄が増える。

単に報酬を受け取って終わるのではなく、クエストが世界の状態を変える。

#### 3. 世界の出来事から生まれる依頼

食料不足

凶作や交易の停滞で村の食料が不足。食料の調達や輸送の依頼が発生する。

商隊の護衛

実際に移動する商隊を護衛。成功すれば商品が目的地に届き、市場の在庫が増える。

魔物討伐

魔物の巣によって街道が危険になった場合、討伐依頼が発生する。

戦争への参加

国家が兵力を必要とすると、傭兵募集、物資輸送、偵察などの依頼が発生する。

#### 4. クエストの結果が世界に残る

例：村の食料不足

凶作が発生

村の食料備蓄が減少

食料調達クエストが発生

村長や商人が依頼を出す

成功

食料が補充され、住民の生活が改善

失敗・放置

飢餓、物価上昇、住民の移住が発生

重要なのは、プレイヤーが依頼を受けなかった場合でも、世界の出来事は進行すること。

NPCの商人が食料を届けて問題を解決する可能性もある。

#### 5. クエストと世界イベントの未確定事項

今回は、依頼の生成、進行、失敗、報酬の基本方針を決めたい。

#### 6. 残りの主要設計分野

クエストの仕様が決まれば、主要なゲームシステムはかなり揃う。

残りは、プレイヤーの操作・UI、移動と高速移動、セーブ・時間経過、キャラクター作成、ゲーム開始条件、世界生成の詳細など。

それらが固まったら、確定仕様を統合して**仕様書v1.0（開発用）**を作成し、実装順序と開発ロードマップを検討する。

なお、今までのv0.1〜v1.3という番号は検討段階の仕様番号であり、ゲームの完成バージョンを意味するものではない。
