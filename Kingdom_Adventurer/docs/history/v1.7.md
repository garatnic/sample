Kingdom Adventurer — 仕様案 v1.7

操作・UI仕様の確定／キャラクター作成・ゲーム開始条件の設計

v1.6の5項目を確定仕様に追加する。

これで、PCとスマホの両方で遊べる2D見下ろし型オープンワールドRPGとして、基本操作が固まった。

特に、移動はプレイヤーが直接操作し、戦闘は自動化できるという方針を維持する。

#### 1. v1.6で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 対応環境 | PC・スマホ両対応 |
| カメラ | プレイヤー追従＋ズーム・視点移動可能 |
| 移動操作 | キーボード・ゲームパッド・仮想スティック |
| 戦闘 | 通常攻撃自動、スキルは手動・自動切替 |
| UI | 表示項目・配置・サイズをカスタマイズ可能 |

操作体系については、PCではキーボードとゲームパッド、スマホでは仮想スティックを利用する。

また、PC・スマホで画面サイズが大きく異なるため、UIは端末に応じて配置を調整できる設計にする。

なお、クリック・タップによる目的地指定移動は採用しない。

#### 2. 次のテーマ：キャラクター作成とゲーム開始

ここまで、プレイヤーの成長方式は「職業固定なし・自由なスキル成長」と確定している。

今回は、ゲーム開始時の主人公をどう作り、どのような立場で世界に登場するかを決めたい。

このゲームではNPCに年齢・家族・職業・経歴があるため、主人公も同じ世界の住人として扱うことができる。

#### 3. キャラクター作成の基本構想

主人公の作成例

名前：自由入力

年齢：20歳

出身：辺境の村

初期職業：なし

得意技能：剣術・採集

数値・設定は例。開始時の能力値や出身による違いは未確定。

職業を固定しないので、ゲーム開始時に剣術が得意でも、途中から魔法使いや商人、鍛冶師へ転向できる。

出身地や過去の経歴は、初期能力やNPCとの関係に影響させることも考えられる。

#### 4. ゲーム開始時の世界

新規ゲームごとに世界を生成する仕様は既に確定している。

そのため、ゲーム開始地点を固定の町にするのではなく、生成された世界の中から選ぶ方式も考えられる。

例えば、平和な農村から始めることも、戦争中の国家の都市から始めることもできる。

また、NPCには家族や経歴があるため、主人公も最初から家族を持つ住人として開始する選択肢がある。

#### 6. 加齢と世代交代について

今回の⑤は、特に重要な選択になる。

既存仕様ではNPCが結婚・出産・加齢・死亡し、世代交代する。

主人公にも寿命を設ける場合、死亡後に子供や後継者へ操作を引き継ぐ仕組みが必要になる可能性がある。

一方、主人公だけ寿命をなくせば、何百年も冒険を続けながら、国家の興亡やNPCの世代交代を観察できる。

どちらも成立するが、ゲームの体験が大きく変わる。

次は、今回のキャラクター作成仕様を確定させた後、主人公の寿命・後継者・セーブ方式・世界の永続性を詳しく検討したい。
