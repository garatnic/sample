# v5.5 家賃・住宅売買価格・複数所有・直接損壊・空き家選択

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 住宅の賃貸料の決め方

- **採用・確定** 立地・広さ・地域の需給・所有者の希望で家賃が変動する
- **不採用（再検討可）** 世界中の住宅で家賃を一律固定
- **不採用（再検討可）** 賃貸住宅の家賃は必ず無料

<a id="q2"></a>
### 2. 住宅売買の価格

- **採用・確定** 広さ・立地・地域需要・取引履歴を考慮して価格を決める
- **不採用（再検討可）** すべての住宅を同一価格で売買
- **不採用（再検討可）** 住宅の売買は常に無償

<a id="q3"></a>
### 3. 住宅の複数所有

- **採用・確定** NPCは資金に応じて複数の住宅を所有・賃貸できる
- **不採用（再検討可）** NPCは必ず住宅を一軒しか所有できない
- **不採用（再検討可）** 住宅所有数に上限はないが売買・賃貸は不可

<a id="q4"></a>
### 4. 住宅の損壊と経年劣化の区別

- **不採用（再検討可）** 経年劣化はしないが災害・戦闘などの直接被害では損壊し得る
- **採用・確定** 災害・戦闘を含め住宅は一切損壊しない
- **不採用（再検討可）** 経年劣化だけ発生し、災害では損壊しない

<a id="q5"></a>
### 5. 移住者の空き家選択

- **採用・確定** 価格・立地・広さ・家族構成・契約条件を比較して入居先を選ぶ
- **不採用（再検討可）** 最初に見つかった空き家へ必ず入居
- **不採用（再検討可）** 空き家の割り当ては完全にランダム

## 既存仕様との整合

- v5.4で空き家の購入・賃貸・無償貸与、親族相続、所有者不在住宅の集落管理を確定。
- v5.4で住宅の経年劣化は永久に発生しないと確定。ただし廃村化による建物削除は別処理。
- v5.3で空き家を優先し、なければ移住時の最低限住宅を無償新築する方針を確定。

## 確定内容の補足

- 家賃は立地・広さ・地域需給・所有者の希望で変動。住宅売買価格は広さ・立地・地域需要・取引履歴を考慮する。
- NPCは資金に応じて住宅を複数所有し、賃貸できる。
- **第4問は第2候補を採用**。住宅は経年劣化せず、災害・戦闘を含め一切損壊しない。ただし廃村化による建物削除（v5.0）は別処理として継続する。
- 移住者は価格・立地・広さ・家族構成・契約条件を比較して空き家を選ぶ。
