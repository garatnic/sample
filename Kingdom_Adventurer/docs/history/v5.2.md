# v5.2 宅地拡張限界・住宅所有・転居・廃村日数・集落名称

[目次](README.md) · [前の版](v5.1.md) · [不採用案の索引](option-index.md) · [次の版](v5.3.md)

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 宅地拡張の上限

- **採用・確定** 地形・通行可能性・他国領を考慮し、拡張可能な場所に限って宅地を増やす
- **不採用（再検討可）** 地形・国境を無視して無限に宅地を増やす
- **不採用（再検討可）** 集落の外側には宅地を拡張できない

<a id="q2"></a>
### 2. 移住住宅の所有権

- **採用・確定** 生成された住宅は移住者世帯の所有物になる
- **不採用（再検討可）** 生成住宅はすべて国家の所有物になる
- **不採用（再検討可）** 住宅は所有者を持たず自由に使用できる

<a id="q3"></a>
### 3. 移住住宅からの転居

- **採用・確定** NPCは収入・家族構成・立地に応じて通常の住宅へ住み替え可能
- **不採用（再検討可）** 移住時の住宅に一生住み続ける
- **不採用（再検討可）** NPCは毎年必ず新しい住宅に移る

<a id="q4"></a>
### 4. 廃村化の猶予日数

- **採用・確定** ゲーム内30日間、定住人口ゼロが続いた場合に廃村化
- **不採用（再検討可）** ゲーム内1日で廃村化
- **不採用（再検討可）** ゲーム内365日で廃村化

<a id="q5"></a>
### 5. 再入植時の集落名称

- **採用・確定** 旧集落名を基本的に引き継ぎ、歴史上は再建として記録
- **不採用（再検討可）** 再入植のたびに必ず新しい名前にする
- **不採用（再検討可）** 集落名を付けず番号だけで管理する

## 既存仕様との整合

- v5.1で宅地不足時の周辺拡張、世界共通住宅モデル、廃村化猶予、廃村跡の再入植、移住時住宅のみ無償生成を確定。
- v5.0で廃村化後も地形・道路・土地履歴・年代記は保持する。
- v5.2は無制限住宅生成と物理的な土地制約の両立、住宅所有、具体的な廃村日数を決める。

## 確定内容の補足

- 宅地拡張は地形・通行可能性・他国領を考慮し、拡張可能な場所に限定。v5.0の資源・費用を消費しない移住住宅生成は継続するが、土地の制約は残る。
- 生成住宅は移住者世帯の所有物。NPCは収入・家族構成・立地に応じて通常住宅へ住み替え可能。
- 定住人口ゼロが**ゲーム内30日間連続**すると廃村化する。期間内の再入植で廃村化を回避（v5.1）。
- 廃村跡への再入植では旧集落名を原則継承し、年代記に再建を記録。道路・地形・土地履歴は保持する。
