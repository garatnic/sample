Kingdom Adventurer — 仕様案 v1.5

クエスト仕様の確定／移動・探索・時間経過システムの設計

v1.4の5項目を確定仕様に追加する。

今回の重要な決定は、クエストに基本的な期限を設けず、NPCもプレイヤーと同じように依頼を受注・達成できること。

これにより、クエストに追われず自由に冒険できる一方、世界そのものは自律的に変化するゲームになる。

#### 1. v1.4で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| クエスト生成 | 世界状況からの自動生成＋固定クエスト |
| NPCの参加 | NPCも自律的に受注・達成・失敗 |
| クエスト期限 | 基本的になし |
| 報酬 | 依頼主が実際に所有する財産・資源から支払う |
| 世界イベント | 自然発生イベント＋固定イベント |

期限なしと自律世界の両立

ここは少し整理が必要になる。

例えば、村の食料不足を解決する依頼を受けた後、プレイヤーが何年も冒険していた場合、村が既に消滅している可能性がある。

そのため、次のように区別する設計を提案する。

クエストの時間制限：原則なし。残り何日というカウントダウンを設けない。

世界の状況変化：通常どおり進行。依頼の目的が消滅する場合がある。

クエストの終了：プレイヤー以外による解決、依頼主の死亡、対象の消滅などで終了する場合がある。

つまり、時間切れで機械的に失敗することは原則ないが、世界の変化によって依頼が成立しなくなることはある。

この扱いは、今回の確定仕様を実現するための補足案として、後の整合性確認で正式に決めよう。

#### 2. 次のテーマ：移動・探索・時間経過

既に確定している探索の基本仕様は、以下のとおり。

| 項目 | 既存の確定仕様 |
| --- | --- |
| 視点 | 2D見下ろし型 |
| フィールド | シームレスなオープンワールド |
| 建物内部・ダンジョン | 別マップ |
| 地図 | 未探索地域は隠され、探索で開示 |
| 世界生成 | 新規ゲームごとに生成、以後は地形を維持 |
| 時間 | 現実30分＝ゲーム内1日 |
| 時間経過 | 睡眠・待機・長期間の時間スキップが可能 |

今回は、この仕組みをプレイヤーがどう操作するかを決めたい。

#### 3. 移動手段の構想

徒歩

基本的な移動方法。探索、採集、NPCとの遭遇などを楽しめる。

騎乗

馬などの乗り物を利用して移動速度を上げる。

馬車・船

交易や大量輸送に利用。NPCの商隊も同じ移動システムを使用する。

高速移動

遠方への移動を短縮。世界の時間経過やNPCの活動との整合性が重要になる。

#### 4. 時間経過と世界シミュレーション

現実30分でゲーム内1日なので、ゲーム内1時間は現実75秒に相当する。

長期間の時間スキップでは、すべてのNPCの行動を1フレームずつ再現するのではなく、出生・死亡・生産・交易・戦争などの結果をまとめて計算する必要がある。

また、時間スキップ中のプレイヤーや仲間の安全、戦争への巻き込まれ方なども検討対象になる。

#### 6. 今後の検討順序

移動と時間操作の仕様が確定したら、次はプレイヤーの操作・UIを検討する。

その後、キャラクター作成・ゲーム開始条件、セーブ方式、世界生成の詳細を決め、これまでの確定仕様を統合する。

特に今後は、ゲームとしての自由度を維持しながら、数千人のNPC・国家・経済・戦争を現実的な処理負荷で成立させるための技術仕様も重要になる。

まだ実装には進まず、まずはゲーム全体の仕様を完成させよう。
