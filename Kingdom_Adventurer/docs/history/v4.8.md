## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。各3択の不採用案も保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. NPCの移住単位

- **採用・確定** 個人・家族が生活条件を考慮して移住し、必要に応じて同行する
- **不採用（再検討可）** NPCは常に個人単位で移住する
- **不採用（再検討可）** NPCは集落全体でしか移住しない

<a id="q2"></a>
### 2. 移住先の住居と仕事

- **不採用（再検討可）** 移住先に住居・仕事の受け皿が必要で、不足すれば移住が抑制される
- **採用・確定** 住居・仕事がなくても移住し、その後自動で確保される
- **不採用（再検討可）** 移住先の受け入れ能力を考慮しない

<a id="q3"></a>
### 3. 集落の衰退・消滅

- **採用・確定** 人口流出・資源不足・施設維持困難により集落が縮小・廃村化する
- **不採用（再検討可）** 集落は成長のみで衰退しない
- **不採用（再検討可）** 人口がゼロになった瞬間に集落と施設を削除する

<a id="q4"></a>
### 4. NPCの移住経路

- **採用・確定** 近距離は実際に移動し遠距離は所要時間・経路条件で簡易処理
- **不採用（再検討可）** すべてのNPC移住を常に実移動で処理
- **不採用（再検討可）** 移住は瞬間的に完了する

<a id="q5"></a>
### 5. 年代記の保存と要約

- **採用・確定** 重要事件は永続保存し、日常記録は期間ごとに要約・圧縮する
- **不採用（再検討可）** すべての記録を無期限に詳細保存する
- **不採用（再検討可）** 一定期間を過ぎた記録は重要度に関係なく削除する

## 検討の背景

- v4.7でNPCの自律移住、集落の自律成長、重要事件の詳細記録と日常記録の要約を確定。
- 既存の近距離実処理・遠距離簡易処理方針とNPC移住の整合を検討する。
- 国家消滅後も住民・施設・歴史を残すv4.4方針と、集落衰退・廃村化を区別する。

## 確定内容と補足

- 個人・家族は生活条件を比較して移住し、必要に応じて同行する。
- **第2問は第2候補を採用**。住居・仕事がなくても移住し、移住後に自動で確保する。確保の所要時間・失敗時の扱いは未確定。
- 集落は人口流出・資源不足・施設維持困難によって縮小・廃村化する。施設を即時削除する方式は不採用。
- 移住は近距離を実移動、遠距離を経路条件・所要時間による簡易処理とする。
- 重要事件は永続保存し、日常記録は期間ごとに要約・圧縮する。
