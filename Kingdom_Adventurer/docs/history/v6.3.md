## 確認事項と選択肢

<a id="q1"></a>
### 1. 家賃改定提案の年内枠の扱い

- **未決定・推奨** 同じ住宅の年1回枠は所有者・借主で共通とし、先に提案した側がその年の枠を使う
- **未決定** 所有者と借主にそれぞれ年1回ずつ枠を設ける
- **未決定** 提案を断られた場合だけ回数を消費しない

<a id="q2"></a>
### 2. 改定提案への回答期限

- **未決定・推奨** 提案を受けた側はゲーム内30日以内に回答し、無回答なら不成立として旧契約を継続する
- **未決定** 回答があるまで交渉を永久に保留する
- **未決定** 提案から1日で自動的に承諾したものとする

<a id="q3"></a>
### 3. 改定交渉の合意判定

- **未決定・推奨** NPCは収支・相場・生活費・関係性を考慮して受諾または拒否を判断する
- **未決定** NPCはすべての提案を必ず承諾する
- **未決定** NPCはすべての提案を必ず拒否する

<a id="q4"></a>
### 4. 月次支払日が来る前の転居

- **未決定・推奨** 合意した新家賃の適用前に退去した場合は新家賃の請求を発生させない
- **未決定** 退去後も新家賃を毎月請求し続ける
- **未決定** 退去した瞬間に新家賃の1年分を請求する

<a id="q5"></a>
### 5. 賃貸契約の交渉履歴の公開範囲

- **未決定・推奨** 住宅取引履歴として閲覧できるが、交渉時の個人資産の詳細までは公開しない
- **未決定** 交渉したNPCの全所持金・資産明細も公開する
- **未決定** 交渉履歴を住宅取引履歴から除外する

## 既存仕様との整合

- v6.2で所有者・借主の双方が値上げ・値下げを提案できると確定。
- v6.2で同じ住宅の改定提案は暦年1回、毎年1月1日に再提案可能と確定。
- v6.2で新家賃は次の月次支払日から適用、交渉結果は住宅取引履歴に保存すると確定。
- v6.1で交渉不成立でも旧契約を継続し退去しないと確定。

## 検討停止・実装時確認の指示（2026-11-24）

- v6.2までの確定事項を維持し、本版の5設問は**未決定**として扱う。
- 家賃・賃貸契約に関する新たな3択や連続検討は行わない。
- 実装時に判断が必要になった項目のみ、既存仕様との整合を確認してユーザーに質問する。
- 仕様検討の次のテーマは住宅・家賃から離れ、冒険・探索・戦闘・NPC・世界の変化などゲームの別領域に移る。
