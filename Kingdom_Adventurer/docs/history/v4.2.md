## 確認事項と選択肢

<a id="q1"></a>
### 1. 国家間の同盟

- **採用・確定** 国家が利害・外交関係に応じて同盟を自律締結・破棄
- **不採用（再検討可）** 同盟は存在するが国家間で固定
- **不採用（再検討可）** 同盟システムを設けない

<a id="q2"></a>
### 2. 同盟国の参戦

- **採用・確定** 同盟国は国益・関係・戦力を考慮して援軍を判断
- **不採用（再検討可）** 同盟国は必ず参戦
- **不採用（再検討可）** 同盟は外交上の関係のみで参戦しない

<a id="q3"></a>
### 3. 戦争による民間経済への影響

- **不採用（再検討可）** 戦闘地域の治安・交易・労働・物価が変動
- **不採用（再検討可）** 戦争は税収と人口にのみ影響
- **採用・確定** 戦争は軍事と領土だけに影響

<a id="q4"></a>
### 4. 反乱・独立

- **不採用（再検討可）** 住民の不満や国家の弱体化に応じて反乱・独立が発生
- **不採用（再検討可）** 国家崩壊時にのみ分裂
- **採用・確定** 反乱・独立は発生しない

<a id="q5"></a>
### 5. 外交交渉の手段

- **不採用（再検討可）** 国家間で同盟・通商・停戦・賠償などを条件交渉
- **採用・確定** 友好・敵対の関係値のみ管理
- **不採用（再検討可）** 外交は戦争と和平だけに限定

## 確定内容と整合性の注意

- 同盟は利害・外交関係によって自律的に締結・破棄する。援軍参加は同盟国が国益・関係・戦力を考慮して判断する。
- 戦争は軍事・領土のみに影響する。民間の治安・交易・労働・物価への戦争固有の直接効果は採用しない。
- 反乱・独立は発生しない。ただし未所属地での建国や国家統合などは別の仕様として検討できる。
- 外交交渉の手段は友好・敵対の関係値のみで管理する。v4.0の和平交渉（領土・賠償・停戦）は確定履歴として残るため、**和平条件の決定方式と外交交渉UIの関係は要整合確認**。
- 以前の仕様にある国家分裂・反乱との相違は後の決定（v4.2）を優先し、過去の記録は消さない。
