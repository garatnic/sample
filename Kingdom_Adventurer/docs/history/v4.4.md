# v4.4 占領と和平・国家統合・継承・建国条件・国家消滅

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。元の3択と不採用案をすべて保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 領土の占領と和平の関係

- **採用・確定** 占領時点で通常統治を開始し、和平時に最終帰属を確定
- **不採用（再検討可）** 占領時点で領有権まで完全確定し和平では変更しない
- **不採用（再検討可）** 和平成立まで通常統治を開始しない

<a id="q2"></a>
### 2. 国家統合の成立条件

- **採用・確定** 友好関係・国力差・指導者判断に応じて自律統合
- **不採用（再検討可）** 友好関係値が一定以上なら必ず統合
- **不採用（再検討可）** 国家統合はプレイヤーが指導する国家のみ可能

<a id="q3"></a>
### 3. 指導者交代の継承ルール

- **採用・確定** 政治体制ごとに世襲・選挙・指名などを使い分ける
- **不採用（再検討可）** すべての国家で世襲のみ
- **不採用（再検討可）** すべての国家で能力の高いNPCが継承

<a id="q4"></a>
### 4. 建国に必要な条件

- **採用・確定** 未所属地・人口・資金などの条件を満たすと建国できる
- **不採用（再検討可）** 未所属地に到達すれば無条件で建国できる
- **不採用（再検討可）** NPCは自動建国できるがプレイヤーは建国不可

<a id="q5"></a>
### 5. 国家の消滅後の扱い

- **採用・確定** 国家は消滅し旧住民・施設・歴史記録は世界に残る
- **不採用（再検討可）** 国家とともに旧施設・住民情報も削除
- **不採用（再検討可）** 消滅した国家は一定期間後に自動復活

## 検討の背景

- v4.0では占領後の即時通常統治と和平交渉を採用。
- v4.2では反乱・独立なし、外交関係値のみの外交管理を採用。
- v4.3では未所属地での建国、全領土喪失による滅亡、占領・和平での領土変更、自律国家統合、政治体制別の指導者交代を採用。
- 本版はこれらの曖昧さや境界条件を整理する。

## 確定内容の補足

- 占領時に通常統治を開始するが、最終的な領有権は和平で確定する。v4.0の即時通常統治とv4.3の和平による領土変更を両立させる。
- 国家統合は友好関係・国力差・指導者判断を用いて自律的に実施する。v4.2の外交関係値中心の管理と整合させる。
- 政治体制別に世襲・選挙・指名などの指導者交代を行う。
- 未所属地・人口・資金等の条件を満たせばNPC・プレイヤーともに建国可能。
- 国家消滅後も住民・施設・歴史記録は世界に残す。反乱・独立はv4.2の不採用方針を維持。
