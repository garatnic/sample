## 確認事項と選択肢

<a id="q1"></a>

### 1. 建物の配置方法

- **採用** 地形・土地条件が許す範囲で自由配置（既存仕様）
- **不採用** マス目に沿って配置
- **不採用** 建築地点は固定

<a id="q2"></a>

### 2. 建築に必要なもの

- **採用** 資材・労働力・建築時間（推奨）
- **不採用** 資材と費用があれば即時完成
- **不採用** 費用と時間のみ

<a id="q3"></a>

### 3. 領地の管理方式

- **不採用** 直接管理＋NPCへの詳細な委任（既存仕様）
- **不採用** すべて直接管理
- **採用** 基本的にNPCが自動運営

<a id="q4"></a>

### 4. 住民による建築

- **採用** 需要・資金・土地に応じてNPCが自律建築（推奨）
- **不採用** 領主の承認後に建築
- **不採用** プレイヤーのみ建築可能

<a id="q5"></a>

### 5. 税金の仕組み

- **採用** 税率・税目を設定し住民や経済に影響（推奨）
- **不採用** 一律税率のみ変更
- **不採用** 税収は自動計算で変更不可

戦争システムについて

「兵力と能力値中心」は、兵站・地形・士気などを個別に細かく計算する方式を採用しないという意味で整理する。

ただし、戦場でプレイヤーやNPCが実際に戦う場合は、通常の戦闘AIやキャラクター能力が適用される。

つまり、遠方の大規模戦争は簡略計算し、プレイヤーが参加する戦闘は詳細に処理するという、以前確定した3段階シミュレーションとも整合する。

#### 2. 次のテーマ：領地・建築・国家運営

これまでに、プレイヤーは土地を所有し、建物を建て、商店や工房を経営し、領主や国家指導者になることができると決めている。

また、所有者のいない土地は自由に取得でき、NPCも自律的に集落を建設・拡大する。

今回は、土地の取得、建築の自由度、領地の管理、住民の自治を具体化する。

発展の一例。必ずこの順番で成長するわけではない。

建築した建物は、単なる装飾ではなく、実際の世界シミュレーションに関係する。

例えば、農場は食料を生産し、工房は商品を製造し、住宅は住民の生活を支える。

NPCが建築や経営を担当すれば、プレイヤーが冒険している間も領地が活動し続ける。

#### 4. 領地管理と冒険の両立

プレイヤーが国家を建設した場合でも、常に城に留まって指示を出す必要はない設計を目指す。

例えば、信頼できるNPCを領地の管理者に任命し、税収・建築・雇用・防衛などを任せられる。

一方で、プレイヤー自身が細かく指示して領地を発展させることも可能にする。

この「直接管理と委任の両立」は既に基本方針として確定しているため、今回は委任の範囲や建築方法などを選ぶ。

#### 6. 次の検討予定

v3.0が確定したら、次は組織・ギルド・雇用・仲間の管理を詳しく決める。
