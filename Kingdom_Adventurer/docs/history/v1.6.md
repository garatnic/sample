## 当時の要件・懸念・検討の経緯

Kingdom Adventurer — 仕様案 v1.6

移動・時間経過仕様の確定／操作・UIシステムの設計

v1.5の5項目を確定仕様として追加する。

今回の決定によって、広大な世界を自由に探索できる一方、移動中も世界の時間が進み、NPCや国家が活動を続けるという基本方針が固まった。

#### 1. v1.5で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 移動手段 | 徒歩・騎乗・馬車・船など複数 |
| 高速移動 | 発見済みの拠点・都市へ移動可能 |
| 高速移動中の時間 | 移動距離に応じてゲーム内時間が経過 |
| 時間操作 | 一時停止・通常速度・早送りを切り替え可能 |
| 長期間の時間スキップ | 安全な場所でのみ実行可能 |

高速移動は単なる瞬間移動ではなく、移動に必要な時間を世界シミュレーションへ反映する。

例えば、遠くの都市へ高速移動すると、その間にNPCの生産・交易・移住や国家間の戦争が進行する。

なお、高速移動中に襲撃などが発生するか、早送り中の戦闘をどう扱うかは未確定のままとする。

#### 2. 次のテーマ：操作・UI

ここからは、これまで決めた膨大なゲームシステムを、プレイヤーがどう操作するかを考える。

Kingdom Adventurerには冒険、戦闘、NPCとの交流、商売、建築、国家運営まで存在する。

そのため、普段はシンプルな冒険画面で遊べて、必要なときだけ詳細な管理画面を開ける設計を推奨する。

#### 3. 通常の冒険画面の構想

冒険画面の概念図。実際のグラフィックや配置は未確定。

画面の中心はあくまでフィールド。

HP・MP、ミニマップ、スキル、仲間の状態などを周辺に配置し、世界を見渡せる領域を確保する。

国家運営や経済の詳細は別画面で扱う。

#### 4. 管理画面の構成案

| 画面 | 主な機能 |
| --- | --- |
| キャラクター | 能力値、スキル、熟練度 |
| インベントリ | 装備、アイテム、重量 |
| 世界地図 | 探索状況、都市、国家、移動 |
| 仲間管理 | 装備、AI方針、雇用契約 |
| クエスト | 依頼、進捗、報酬 |
| 拠点管理 | 建築、施設、従業員、在庫 |
| 国家管理 | 領土、外交、軍事、税制 |
| 世界史 | NPCの人生、戦争、国家の変遷 |

特に世界史は、このゲームの特徴になる。

例えば、何十年も前に一緒に冒険したNPCが、その後どんな人生を送ったかを確認できるようにしたい。

#### 5. v1.6で確定したい5項目

今回は操作環境、カメラ、戦闘操作、UIの表示方法を決める。

#### 6. 今後の設計

操作・UIが決まったら、キャラクター作成とゲーム開始条件を検討する。

その後は、セーブ方式、世界生成の詳細、ゲームバランス、技術構成を決める。
