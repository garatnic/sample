## 更新方法

順引きのファイルと仕様IDの組から逆引きを導出する。両方向に過不足がないこと、仕様IDと参照先、ファイル・シンボル、件数、基準日・版・実装SHAおよびテストの登録状況が最新であることを完了時に確認する。名称変更・追加・削除・移動の際は両方向を更新する。廃止IDは履歴を残し再利用しない。開発タスクIDはTODOで管理する。
