# コード整理の実施計画

根拠は [全ソースコード棚卸し](SOURCE_CODE_AUDIT.md)。基準は同書の main・ver.57・形式15。実施はユーザーが調査結果を確認し、承認した工程から開始する。この計画の登録はコード変更の承認を意味しない。

## 共通の開始・終了条件

- 着手時に最新mainとAGENTSを確認し、当該IDの基準からの差分だけ照合する。依存・仕様が変わった場合はその候補を再分類し、別工程へ移す。
- 変更前に既存テストを実行する。各工程で対象の回帰を行い、全テストの出力と純減を記録。フレーム性能を扱うときは端末、ブラウザ、画面幅、解像度、固定シード、経過時間をそろえる。
- 現行仕様・保存判定・MOB/国家/冒険者の周期は保護する。実装時の表示版・キャッシュと形式番号は開発基本方針に従い、番号更新の要否を個別判断する。
