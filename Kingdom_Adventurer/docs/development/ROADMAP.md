# 開発ロードマップ

開発工数の均等配分は求めない。個別項目は [TODO](TODO.md) で管理し、順序は依存関係と遊びやすさに応じて見直す。

## Phase 1 — 最小ゲーム
固定の街と宿、フィールド、移動、敵出現、基本戦闘、HP回復を備えた遊べるゲームを作る。
終了条件：街から探索に出て戦闘し、宿に戻り回復する循環が成立し、死亡時にも再開できる。初期対象外の機能を先行実装しない。

## Phase 2 — 反復開発
主要機能の追加と既存機能の詳細化を繰り返す。横方向の拡張を優先するが、依存関係や遊びやすさのために必要な詳細化は随時行う。全機能が揃うまで詳細化を禁止しない。
終了条件：全15分野の主要機能が実装され、残る詳細・不足が TODO に明示され、全体照合に移れる状態。

Phase 2の技能開発は片手武器で共通基盤を整え、次に個別技能を追加し、パークを段階的に実装する（DEV-062〜064）。

Phase 2の世界シミュレーションは、2国家の採集・運搬・日次消費・建築・住宅人口を最初の段階とする（DEV-066）。生成シード、3段階処理、複数都市と開拓、住民の生活と経済、国家間関係は既存の目標仕様に沿って後続で実装する（DEV-068）。

国家経済の最初の段階として、専属職と一般住民の行動、生活備蓄、余剰資源、国庫・商店間の精算を実装済み（DEV-080）。国家間交易と国家支出の具体化は後続で扱う。

野外の通常MOBはチャンク密度と自由徘徊を導入し、住民との接触戦闘と保存に対応する（DEV-074）。次に、実機負荷と長期の地域密度を測定して暫定値を調整する。

## Phase 3 — 全仕様照合・不足解消
全統合仕様と出典、実装、TODO を照合し、未実装・簡易実装・相違・矛盾・登録漏れを洗い出して解消する。未決事項は必要に応じユーザー確認。
終了条件：確定仕様の実装・検証が完了し、未解決の差異がない（変更・延期はユーザー承認を記録）。

## Phase 4 — 最終調整・完成
操作性、UI、グラフィック、バランス、性能、安定性を調整する。新たな不足は TODO に追加し、必要なら前Phaseへ戻る。
終了条件：最終仕様との整合、主要な遊び方の動作、対象環境での安定性を確認し、完成判断を行う。

現在のPhase：2（反復開発中）。詳細な開発順序は固定しない。
