# ゲーム基本構想

## 実装・変更時の原資料確認義務

本資料は、historyフォルダに保存された仕様検討履歴を分野別に整理・統合したものであり、原資料を代替するものではない。

本資料に記載された仕様について、新規実装、既存実装の変更、修正、拡張、設計判断を行う場合は、作業着手前に、対象仕様の出典として記載されたhistory内の原資料を必ず全文確認すること。

統合仕様書のみを参照して実装することは禁止する。

原資料に記載された要件、採用理由、ユーザーの補足、適用条件、例外、後続の変更内容を確認し、仕様の意図を損なわないようにすること。

統合仕様書と原資料の内容に相違がある場合は、原資料におけるユーザーの最新の明示的な決定を優先すること。

ただし、原資料同士に矛盾があり、最新の有効な仕様を明確に判断できない場合は、独自判断で解決せず、要確認事項として記録すること。

この確認義務は、人間の開発者とAIによる自律開発の双方に適用する。

## GAME-001 冒険の主な目的

Kingdom Adventurerは自律して変化する世界を一人の冒険者として自由に生きる2D俯瞰型RPG。冒険・商売・建築・国家運営などから自分で目的を選ぶ。メインストーリー進行は義務化しない。
ゲーム形式はオープンワールド。プレイヤーの行動がなくてもNPC・集落・国家・魔物は自律して活動する。

**出典**

- [v0.2.md](../history/v0.2.md#1-確定した基本仕様) 基本仕様のゲーム形式・操作対象・世界

## GAME-003 探索を続ける最大の動機

探索を続ける中心動機は未知の土地・遺跡を発見し、魔物の生態やNPC・国家の変化を追うこと。戦利品・成長・生活・開拓も並立する。

**出典**

## GAME-004 大きな世界の変化への参加方法

大事件には戦闘、交渉、交易、支援など複数の手段で関与できる。戦争固有の民間経済への直接効果を設けない方針は維持する。

**出典**

- [v6.6.md Q2](../history/v6.6.md#q2) 大きな世界の変化への参加方法 ／ 採用「魔物の侵攻・新天地の開拓・国家間の争いなどに、戦闘・交渉・交易・支援など複数の手段で介入できる」

## GAME-005 プレイヤーが起こした重大な変化の扱い

国家滅亡・集落消滅など重大な変化は原則巻き戻さず、歴史と結果を引き継いで進行する。廃村後の再入植と国家滅亡後の住民・施設の存続はそれぞれの規則に従う。

**出典**

- [v6.7.md Q3](../history/v6.7.md#q3) プレイヤーが起こした重大な変化の扱い ／ 採用「国家の滅亡や集落の消滅など大きな変化も原則そのまま歴史として残り、世界は新しい状態から進行する」
