# キャラクター成長

## 実装・変更時の原資料確認義務

本資料は、historyフォルダに保存された仕様検討履歴を分野別に整理・統合したものであり、原資料を代替するものではない。

本資料に記載された仕様について、新規実装、既存実装の変更、修正、拡張、設計判断を行う場合は、作業着手前に、対象仕様の出典として記載されたhistory内の原資料を必ず全文確認すること。

統合仕様書のみを参照して実装することは禁止する。

原資料に記載された要件、採用理由、ユーザーの補足、適用条件、例外、後続の変更内容を確認し、仕様の意図を損なわないようにすること。

統合仕様書と原資料の内容に相違がある場合は、原資料におけるユーザーの最新の明示的な決定を優先すること。

ただし、原資料同士に矛盾があり、最新の有効な仕様を明確に判断できない場合は、独自判断で解決せず、要確認事項として記録すること。

この確認義務は、人間の開発者とAIによる自律開発の双方に適用する。

### 技能とキャラクターレベルの詳細（GROWTH-001・006・008・010）

| 分類 | 採用技能 |
|---|---|
| 戦闘系 | 片手武器、両手武器、弓術、防御、重装、鍛冶 |
| 魔法系 | 破壊、回復、召喚、幻惑、変性、付呪 |
| 隠密系 | 隠密、開錠、スリ、話術、軽装、錬金術 |

- 決定済み。基本値15、通常上限100、技能ごとの独立経験値。対応する行動でXPを得て、高技能ほど次の段階に必要な技能XPが増える。技能別の能力補正と、戦闘・非戦闘の技能上昇を通じたキャラクター成長を採用する。
- 決定済み。技能が1上昇するごとに、上昇後の値をキャラクターXPに加える。次の必要XPは75＋25×現在レベル。余剰を繰り越し、条件を満たす間はレベルアップする。討伐そのものからの直接XPは廃止。
- 片手武器は短剣・片手剣・片手斧・メイス等を対象とし、有効な命中で武器の基礎値を基準に成長する。武器基礎攻撃力に1＋技能値÷200を掛ける。現行武器と暫定調整値は現行仕様書を参照。
- 両手武器も有効命中で成長し、現行では鉄の槌が対象。技能値による両手武器の能力補正は今後検討する。残り16技能は名称・分類を採用済み。成長条件・効果はSkyrimを基に技能単位で検討し実装する。将来はNPCにも技能成長の共通処理を適用する方針。
- 将来構想。技能別のパークツリーを持ち、キャラクターレベル上昇で得るパークポイントを消費して取得する。必要技能値と前提パークを条件にでき、取得により特殊能力・追加効果を得る。個別パークは本作向けに検討する。
- 未決定。将来の基礎ステータス強化方式、技能個別の詳細、NPC適用時の条件、パーク個別設計と進行バランス。
