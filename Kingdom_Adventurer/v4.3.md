# v4.3 建国・滅亡・領土移動・国家統合・指導者交代

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。以下は実際に提示した各3択をすべて保存したもの。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 新しい国家の成立

- **採用・確定** 未所属の土地にNPCやプレイヤーが建国できる
- **不採用（再検討可）** ゲーム開始時に生成された国家だけが存在する
- **不採用（再検討可）** 既存国家の滅亡後にのみ新国家が成立する

<a id="q2"></a>
### 2. 国家の滅亡条件

- **採用・確定** すべての領土を失うと滅亡する
- **不採用（再検討可）** 国庫が枯渇しても滅亡する
- **不採用（再検討可）** 国家は滅亡せず領土ゼロでも存続する

<a id="q3"></a>
### 3. 国家間の領土移動

- **採用・確定** 戦争による占領と和平で領土が変わる
- **不採用（再検討可）** 戦争に加えて平時の売買・譲渡でも変わる
- **不採用（再検討可）** 領土の移動は戦争による占領のみ

<a id="q4"></a>
### 4. 国家の統合

- **採用・確定** 外交関係に応じて国家同士が自律的に統合できる
- **不採用（再検討可）** 戦争による征服でのみ統合する
- **不採用（再検討可）** 国家統合は行わない

<a id="q5"></a>
### 5. 国家指導者の交代

- **採用・確定** 死亡・任期・政治体制に応じて自律交代する
- **不採用（再検討可）** 死亡時のみ後継者へ交代する
- **不採用（再検討可）** 国家指導者は交代しない

## 確定内容と整合性

- 反乱・独立はv4.2で不採用。新国家の成立は未所属地での建国による。
- 領土をすべて失った国家は滅亡。国家統合は外交関係に基づく自律判断で可能。
- v4.2では外交交渉の手段を関係値のみで管理するため、国家統合の条件は関係値による自律判断と解釈する。詳細な閾値は未確定。
- v4.0の占領時点で通常領地として統治する仕様と、v4.3の和平で領土が変わる仕様について、占領時の暫定的な支配と和平後の帰属確定の関係は要整理。
- 指導者交代は死亡・任期・政治体制に応じて自律処理する。政治体制別の継承条件は今後検討。
