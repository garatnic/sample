## 既存の確定仕様との関係

国家は自律的に外交・戦争・領土変更を行う。軍事行動には国庫・人員・物資が関係し、NPC指導者は予算を自律配分する。戦争の勝敗には兵数と能力が大きく影響し、近距離の戦闘は実際に処理する。今回の設問はそれらの詳細を決める。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 兵士の募集と補充
- **未決定** 人口・志願・給与・国庫に応じてNPCが自律的に募集する（推奨）
- **未決定** 国が必要数を徴兵し、住民の労働力や支持率に影響する
- **未決定** 軍隊は人口と国力に応じて自動的に増減する

<a id="q2"></a>
### 2. 軍隊の編成と運用
- **未決定** NPC指揮官が兵種・部隊・補給を自律編成し、プレイヤーは方針や命令で介入できる（推奨）
- **未決定** 兵数と戦力値のみで部隊を抽象管理する
- **未決定** プレイヤーが全部隊の編成と行動を直接管理する

<a id="q3"></a>
### 3. 開戦の判断
- **未決定** 領土・資源・外交関係・軍事力・財政を総合して国家指導者が自律判断する（推奨）
- **未決定** 領土紛争など限定されたイベントが発生したときのみ開戦する
- **未決定** 国家間の関係値が一定以下になれば自動的に開戦する

<a id="q4"></a>
### 4. 占領地の統治
- **未決定** 軍事占領から行政支配へ段階的に移行し、治安・住民感情・維持費が影響する（推奨）
- **未決定** 拠点を占領した時点で直ちに自国領として安定統治する
- **未決定** 戦争中は占領のみで、和平成立時に領有権をまとめて確定する

<a id="q5"></a>
### 5. 和平交渉と終戦
- **未決定** 戦況・国庫・損害・外交関係に応じて領土割譲・賠償・停戦などを交渉する（推奨）
- **未決定** 一方の国家が降伏するまで戦争を続ける
- **未決定** 一定期間または戦力差によって自動的に終戦する
