## 決定事項

> Kingdom Adventurer v0.2の世界構造は、世界生成：新規ゲームごとに別の世界、移動：地上シームレス・屋内別マップ、規模：大規模で進めたい。次はNPCの生活AI、自律行動、個人情報、死亡や世代交代について具体的に検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. マップの生成と保存

- **採用** 新規ゲームごとに別の世界を生成（推奨） — 開始時に世界を生成し、以後はその世界で冒険する。新しく始めると違う世界になる。
- **不採用** すべてのプレイヤーで同じ世界 — 開発時に一度だけ世界を生成。地形や都市の初期配置は全員共通。

<a id="q2"></a>

### 2. マップの移動方式

- **不採用** 完全シームレス（推奨） — 村から森、山、隣国まで画面切り替えなしで移動する。
- **採用** 地上はシームレス、建物やダンジョンは別マップ — 地上を自由に歩ける一方、屋内や地下は専用エリアとして管理する。
- **不採用** 地域ごとのエリア切り替え — 村、街道、森林などを独立したマップとして管理する。

<a id="q3"></a>

### 3. 世界の規模

- **不採用** 小規模 — 1国家、数個の町、数百人のNPC。密度重視。
- **採用** 大規模（推奨） — 複数国家、数十の集落、数千人規模のNPC。遠隔地は簡易シミュレーション。
- **不採用** 超大規模 — 数十国家、数百の集落、数万人以上のNPC。世界の歴史を長期間シミュレーション。

## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

ここまでの決定事項を整理して、Kingdom Adventurer 仕様案 v0.2 としてまとめよう。

今回のゲームは「Kingdom Observerの世界を、一人の冒険者として体験する」という方向性を維持する。

ただし、単にNPCや魔物がたくさんいるRPGではなく、世界が自律的に変化し、その変化にプレイヤーが介入できることをゲームの中心に据える。

#### 1. 確定した基本仕様

| 項目 | 決定内容 |
| --- | --- |
| ゲーム形式 | 2D俯瞰型オープンワールドRPG |
| 操作対象 | 一人の冒険者 |
| 戦闘 | 半自動リアルタイム戦闘 |
| 世界生成 | 自動生成された固定世界 |
| 成長 | 冒険者レベル＋スキル熟練度 |
| 死亡 | ペナルティ付き復活 |
| 仲間 | NPCを雇用して同行可能 |
| 世界 | NPC・集落・国家・魔物が自律活動 |

「自動生成された固定世界」は、最初に世界を生成し、その後は地形を維持する方式として仮に解釈する。

地形は固定でも、建物、集落、道路、勢力図、住民の生活は変化できる。

また、死亡ペナルティの具体的な内容や仲間の人数は、まだ決めていない。

#### 2. 次に設計するシステム

今回は、ゲーム体験に直結する5分野を検討したい。

① 世界とマップ

世界の広さ、地形生成、シームレス移動、未探索地域、ダンジョンの構造。

② NPCと生活AI

NPCの仕事、移動、会話、友好関係、依頼、雇用、死亡と世代交代。

③ 戦闘と成長

敵の強さ、攻撃速度、スキル、魔法、装備、経験値、仲間の戦闘AI。

④ 経済とアイテム

採集、製作、装備品質、交易、物価、戦利品、所持重量。

⑤ 国家と世界の変化

国家間戦争、領土拡大、都市の発展、魔物の侵攻、プレイヤーの影響力。

この5つは相互に関係するので、細部を独立して決めるより、まず世界の基本的な振る舞いを決める方がよい。

#### 3. 最初に決めたいのは「世界の構造」

ここには重要な選択が3つある。

規模は設計目標。実際の同時処理人数やマップ面積は性能検証後に確定する。

#### 4. 私からの追加提案

今回のゲームでは、「世界を広くすること」と「世界を生きているように感じさせること」を分けて考えたい。

例えばNPCが1万人いても、全員が同じように歩き回るだけでは面白くない。

それより、商人が盗賊に襲われて死亡し、その商人と取引していた村の物価が上がり、代わりの商人が交易路を開拓する、といった出来事が起こる方が重要。

だから、世界の広さを決めた後は、NPCの個人単位のシミュレーションをどこまで行うか検討したい。

世界構造の選択を反映する

NPCの設計は、既存のKingdom Observerとの共通化を考えるうえでも特に重要になる部分だと思う。
