## 決定事項

> Kingdom Adventurer v2.0のNPC・世界シミュレーション仕様として、処理方式：周辺詳細・近隣簡略・遠方集約の3段階。NPCデータ：全NPCの個人情報・家族・財産・履歴を保持。遠方の出来事：経済・出生死亡・移住・戦争などが自律進行。処理負荷対策：端末性能に応じて更新頻度・描画数を自動調整。歴史の保存：重要イベントを永続保存し日常行動は要約。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 世界シミュレーションの処理方式

- **採用** 周辺詳細・近隣簡略・遠方集約の3段階（推奨）
- **不採用** 周辺詳細・遠方簡略の2段階
- **不採用** 世界全体を同じ精度で計算

<a id="q2"></a>

### 2. NPCの個人データ

- **採用** 全NPCの個人情報・家族・財産・履歴を保持（推奨）
- **不採用** 重要NPCのみ詳細保持
- **不採用** 遠方NPCは人口統計のみ

<a id="q3"></a>

### 3. プレイヤー不在地域の出来事

- **採用** 経済・出生死亡・移住・戦争など自律進行（推奨）
- **不採用** 経済と人口のみ進行
- **不採用** プレイヤー不在地域は停止

<a id="q4"></a>

### 4. PC・スマホの処理負荷対策

- **採用** 端末性能に応じて更新頻度・描画数を自動調整（推奨）
- **不採用** 全端末で同じ処理設定
- **不採用** ユーザーが手動で調整

<a id="q5"></a>

### 5. 世界の歴史の保存

- **採用** 重要イベントを永続保存、日常行動は要約（推奨）
- **不採用** 全NPCの全行動を永続保存
- **不採用** 集落・国家の統計のみ保存

Kingdom Adventurer — 仕様案 v2.0

世界生成仕様の確定／NPC・世界シミュレーションの設計

v1.9の5項目を確定仕様に追加する。

今回の大きな変更は、標準の世界規模を中規模にし、巨大な単一大陸を中心にすること。

これまでの「数千人のNPCが生活する大規模世界」という構想を完全に捨てるのではなく、標準設定を中規模にして、世界生成オプションで規模を変更できる設計にする。

#### 1. v1.9で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 標準世界規模 | 数国家・十数集落の中規模 |
| 地形 | 巨大な単一大陸中心 |
| 環境生成 | 地形・気候・資源・生態系を連動 |
| 開始時の歴史 | 過去の歴史を事前シミュレーション |
| 生成オプション | 世界規模・国家数・地形などを調整可能 |

ここで、以前の「複数国家・数十集落・数千NPC」という規模は、標準値ではなく大規模設定の候補として扱う。

なお、標準世界の人口数はまだ確定していない。

#### 2. 次のテーマ：世界シミュレーション

Kingdom Adventurerの中心となるのは、プレイヤーが操作していない場所でも、NPCが生活し、国家が変化すること。

ただし、すべてのNPCを常に詳細に動かすと、PCでもスマホでも処理負荷が大きくなる。

そこで、世界全体の出来事は継続させながら、場所によって計算の細かさを変える仕組みを検討する。

#### 3. シミュレーションの3段階

(詳細) プレイヤー周辺

NPCの歩行、会話、戦闘、採集、建築などをリアルタイムに処理する。

(簡略) 近隣の集落・地域

個人の仕事・移動・取引を、時間単位などのまとめた処理で更新する。

(集約) 遠方の国家・集落

人口、資源、経済、外交、戦争などを集約して計算する。必要なときに個人単位の状態へ反映する。

この方式なら、例えば遠くの国で戦争が起きても、その国の兵士全員を画面外でリアルタイムに動かす必要はない。

一方、プレイヤーが戦場へ近づけば、兵士や部隊を実際に表示して戦闘を進行させられる。

#### 4. 重要なのは「計算を省略しても歴史がつながる」こと

例えば、遠方の村で次の出来事が起きたとする。

ある村の10年間 シミュレーション例

人口120人。農業と木材生産が中心。

豊作が続き、人口が150人に増加。

商人が移住して交易所を開設。

隣国との戦争で交易が減少。

プレイヤーが訪問すると、人口135人の村として表示される。

このとき、過去10年間の住民全員の歩行経路を保存する必要はない。

しかし、出生・死亡・移住・商店の開業・戦争などの重要な出来事は、個人や集落の履歴と矛盾しないように保存する必要がある。

#### 5. v2.0で確定したい5項目

今回は、世界シミュレーションの基本方針を決める。

#### 6. 今後の検討

世界シミュレーションの方針が確定したら、次は人口・出生・死亡・移住の具体的な計算方法を検討したい。

その後、経済・交易の詳細、戦闘バランス、技術構成、開発ロードマップへ進む。

特に重要なのは、NPCの個人データを保持しながら、遠方の処理を簡略化する仕組み。

これが成立すれば、PC・スマホ両対応でも、世代を超えて成長する世界を実現できる可能性が高まる。
