## 確認事項と選択肢

<a id="q1"></a>

### 1. NPCの性格

- **採用** 複数の性格パラメータを組み合わせる（推奨）
- **不採用** 固定の性格タイプを1つ設定
- **不採用** 性格差は最小限

<a id="q2"></a>

### 2. NPCの人生の目標

- **採用** 状況や経験に応じて目標が変化（推奨）
- **不採用** 生涯固定の目標を持つ
- **不採用** 長期目標なし・短期判断のみ

<a id="q3"></a>

### 3. NPCの記憶

- **採用** 重要な出来事や人物との関係を長期記憶（推奨）
- **不採用** 経験した全出来事を詳細に保存
- **不採用** 最近の出来事のみ記憶

<a id="q4"></a>

### 4. NPC同士の人間関係

- **不採用** 好意・信頼・尊敬・恐怖・恨みなど複数要素（推奨）
- **採用** 友好度の単一数値
- **不採用** 友人・中立・敵対の3段階

<a id="q5"></a>

### 5. NPCが知っている情報の範囲

- **不採用** 見聞き・噂・伝聞などで得た情報のみ（推奨）
- **採用** 世界の全情報を把握
- **不採用** 所属地域の情報はすべて把握

## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

Kingdom Adventurer — 仕様案 v2.7

ダンジョン仕様の確定／NPCの意思決定・性格・人間関係

v2.6の5項目を確定仕様に追加する。

これで、ダンジョンは単に攻略して終わる場所ではなく、時間とともに変化し、周辺地域の治安や経済にも影響する場所として位置づけられた。

次は、この世界で暮らすNPCが、どのように自分の行動を決めるのかを設計する。

#### 1. v2.6で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| ダンジョンの変化 | 攻略後も新勢力の占拠・環境変化が発生 |
| 魔物の巣 | 種類・環境・時間に応じて再出現 |
| 財宝・資源 | 一定期間で宝箱・資源が復活 |
| 発見方法 | 探索・噂・地図・NPC情報 |
| 攻略の影響 | 治安・交易・住民生活・勢力関係に影響 |

既存仕様との整合性

今回、宝箱・資源の定期的な復活を採用したため、以前確定した「実在するアイテムと財産を管理する経済」との整合性を取る必要がある。

現段階では、ダンジョンの再補充は例外的なアイテム供給源として扱う方針が妥当。

ただし、誰が宝箱を補充するのか、固有の伝説装備まで復活するのか、再補充に上限があるのかは未確定とする。今回の選択を勝手に変更することはしない。

#### 2. 次のテーマ：NPCの自律的な意思決定

Kingdom Adventurerでは、NPCは単なる背景ではない。

例えば、あるNPCが次のような人生を送ることも考えられる。

NPC：ある村の若者

村の農家に生まれ、家業を手伝う。

冒険者に憧れ、剣術を訓練する。

村を出て、近くの都市へ移住する。

冒険者として活動し、仲間を作る。

ダンジョンで財宝を発見して裕福になる。

故郷へ戻り、商店を開業する。

結婚して子供を育て、財産を次世代へ残す。

NPCの人生の例。特定の行動を必ず行うという意味ではない。

こうした人生を実現するためには、NPCが自分の目的や状況に応じて行動を選ぶ必要がある。

#### 3. NPCの判断材料

NPCの意思決定には、例えば次の要素を使える。

性格

勇敢・慎重・強欲・親切など

人間関係

家族・友人・恋人・敵対関係など

人生の目標

富・名声・安全・権力・冒険など

経験と記憶

過去の成功・失敗・恩義・恨みなど

これらを組み合わせれば、同じ状況でもNPCごとに異なる行動を選べる。

例えば、魔物に襲われたとき、勇敢なNPCは戦い、慎重なNPCは逃げ、家族を守りたいNPCは家族を優先する、といった違いを表現できる。

#### 4. v2.7で確定したい5項目

#### 5. 今後の検討

NPCの意思決定が固まったら、次はNPCとの会話・交渉・依頼・噂の伝播を詳しく設計したい。

特に、今回の⑤で「NPCが知っている情報には限界がある」を採用すると、噂や情報そのものが世界を動かす重要な要素になる。

例えば、遠方で起きた戦争を商人が別の街へ伝え、その情報を聞いた住民が移住を決意するといった連鎖が実現できる。

この仕組みは、プレイヤーが情報収集をする意味にも直結する。
