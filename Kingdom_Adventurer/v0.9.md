Kingdom Adventurer — 仕様案 v0.9

魔物・ダンジョン仕様の確定／装備・アイテム・製作システムの設計

今回の決定で、魔物の生態とダンジョンの基本的な仕組みが確定した。

特に、魔物の巣は固定配置で定期復活する一方、ダンジョンは攻略結果が保存され、時間経過によって変化するという組み合わせが特徴になる。

これなら魔物の討伐を繰り返す楽しさを残しつつ、世界が変化する感覚も維持できる。

#### 1. v0.8で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 魔物の発生 | 生態系＋補助的なランダム出現 |
| 魔物の巣 | 固定配置・定期復活 |
| ダンジョン | 攻略結果を保存し、時間経過で変化 |
| ボス | 固有個体と通常の強敵が共存 |
| 地域危険度 | 地域の基本危険度＋強い個体が混在 |

なお、巣の「定期復活」とダンジョンの「永続的な変化」は区別して扱う。

例えば巣の魔物を倒しても、一定期間後に新しい魔物が住み着く。一方、ダンジョンで開けた扉や破壊した設備、取得済みの固有アイテムなどは保存される。

これは両方の仕様を成立させるための設計案で、復活周期などは今後決める。

#### 2. 装備システムの基本構想

装備は、プレイヤーの成長だけでなくNPCの経済とも結びつけたい。

例えば、同じ鉄の剣でも製作者の鍛冶熟練度、材料の品質、製作時の結果によって性能が異なる。

さらに、魔物から得た特殊素材を使うことで、追加効果を持つ武器を作れる。

装備の基本構成案

| 分類 | 例 |
| --- | --- |
| 片手武器 | 剣、斧、短剣、槌 |
| 両手武器 | 大剣、戦斧、槍、杖 |
| 遠距離武器 | 弓、クロスボウ |
| 魔法武器 | 魔法杖、魔導書 |
| 防具 | 頭、胴、腕、脚、足 |
| 補助装備 | 盾、指輪、首飾り |

装備できる種類は職業で制限せず、能力や熟練度によって使いこなしやすさが変わる方式を推奨する。

#### 3. アイテムの品質とランダム性能

品質・ランダム性能・特殊効果は既に確定している。

ここでは、品質をどのように表現するか考えたい。

例：鉄の剣

品質と性能の例。数値・段階は未確定。

ただし、品質だけで装備の強さが決まると、低品質の装備が完全に無価値になる。

そのため、重量、攻撃速度、耐久度、素材価値などにも違いを持たせると、装備選択に幅が出る。

#### 4. 製作と経済の接続

採集・採掘・魔物討伐

鉱石、木材、皮革、魔物素材

加工・製作

商人、店舗、交易路、市場在庫

装備、消費、修理、売却

ここで重要なのは、NPCが製作した装備もプレイヤーが製作した装備も、同じアイテムデータを使うこと。

これによって、NPCが作った剣を商人が運び、別の町の衛兵が購入して装備するといった流れが成立する。

#### 6. 今後の検討

次は、仲間NPCの雇用・成長・装備・戦闘方針と、プレイヤーとの人間関係を具体化したい。

その後、建築・拠点・領地経営・国家間戦争を設計する。

なお、既に決まっている「仲間NPCは永久死亡しない」という仕様については、一般NPCとの切り替え条件も明確にする必要がある。

例えば、仲間として雇用中だけ死亡保護されるのか、一度仲間になったNPCは解雇後も死亡しないのかで、世界シミュレーションへの影響が変わる。

この点は次の仲間システムの設計で扱おう。
