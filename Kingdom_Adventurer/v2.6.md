## 確認事項と選択肢

<a id="q1"></a>

### 1. ダンジョン攻略後の変化

- **採用** 新勢力の占拠・環境変化などが発生（推奨）
- **不採用** 一定期間で元の状態へリセット
- **不採用** 攻略後は基本的に空のまま

<a id="q2"></a>

### 2. 魔物の巣の再出現

- **採用** 巣の種類・環境・時間に応じて再出現（推奨）
- **不採用** 固定時間で再出現
- **不採用** 一度討伐した巣は再出現しない

<a id="q3"></a>

### 3. 財宝・資源の再配置

- **不採用** 固有財宝は復活せず、新たな物資は世界内から流入（推奨）
- **採用** 一定期間で宝箱・資源が復活
- **不採用** 固有財宝は復活せず、一般資源は定期復活

<a id="q4"></a>

### 4. ダンジョンの発見方法

- **採用** 探索・噂・地図・NPC情報から発見（推奨）
- **不採用** 最初から地図に表示
- **不採用** 探索中にランダム発見

<a id="q5"></a>

### 5. ダンジョン攻略の世界への影響

- **採用** 治安・交易・住民生活・勢力関係などに影響（推奨）
- **不採用** クエストや報酬にのみ影響
- **不採用** ダンジョン内部の変化のみ

Kingdom Adventurer — 仕様案 v2.6

装備・戦利品仕様の確定／ダンジョン・探索・魔物の巣

v2.5の5項目を確定仕様に追加する。

今回の決定によって、アイテムが世界の中で実際に生産・所有・移動・消費されるという仕組みが、戦利品や装備にも適用されることになった。

#### 1. v2.5で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 戦利品 | 敵が実際に所有していた装備・財産・素材を入手 |
| 装備品質 | 素材・製作者技能・製作条件・個体差で決定 |
| 希少装備 | 固有の伝説装備とランダム生成の希少装備が共存 |
| 装備条件 | 装備は柔軟に可能。能力・技能によって性能が変化 |
| アイテム永続性 | 保管・設置・売買したアイテムを世界に保持 |

アイテム永続性について

例えば、プレイヤーが剣を自宅の宝箱に保管すれば、何年後でも同じ剣を取り出せる。

NPCに売却した場合も、その剣はNPCや商店の所有物として残り、別のNPCに販売される可能性がある。

ただし、消費・破壊されたアイテムまで永久に存在させるわけではない。

同種の素材などをまとめて管理する内部最適化は許容しつつ、所有権・数量・品質・特殊効果などの情報を失わないことを基本とする。

#### 2. 次のテーマ：ダンジョンと探索

これまでに確定している探索関連の仕様は次のとおり。

世界地図は未探索部分が隠され、探索によって開示される。

固定ダンジョンと自動生成ダンジョンが存在する。

ダンジョンの内部はフィールドとは別のマップ。

ダンジョンの攻略状況は世界に保存される。

魔物の巣は固定位置に存在し、一定期間で再出現する。

ユニークボスと通常より強い個体が存在する。

世界の危険度には地域差があるが、プレイヤーレベルには連動しない。

今回は、ダンジョンが世界の中でどう変化するか、探索する動機をどう作るかを決める。

#### 3. ダンジョンの変化

同じダンジョンの時間経過例

発見時魔物が住み着き、宝箱や資源が残っている。

攻略直後魔物が倒され、持ち去った財宝はなくなる。

数年後新たな魔物や盗賊が住み着く可能性がある。

さらに時間経過ダンジョンの所有者や用途が変わることもある。

これは検討用の例。再占拠や用途変更はまだ未確定。

ここで重要なのは、攻略済みのダンジョンが、何事もなかったように完全初期化されるわけではないということ。

過去に倒した固有ボスや持ち去った財宝などは、その後の世界にも反映させたい。

#### 4. 魔物の巣と周辺地域

魔物の巣は、周辺の街道や村の安全に影響する存在として設計できる。

例えば、巣の周辺で魔物の出現が増えると、商隊が襲われたり、住民が危険を感じて移住したりする。

冒険者が巣を討伐すれば、一時的に安全が回復する。

こうした仕組みなら、ダンジョン攻略が単なる戦利品集めではなく、世界の変化につながる。

#### 6. 今後の検討

ダンジョン仕様の次は、NPCの意思決定・性格・人間関係を詳しく設計する予定。

特に、NPCがプレイヤーの指示なしに冒険・商売・移住・結婚・戦争参加などを判断する仕組みは、このゲームの重要な部分になる。

世界の経済、人口、戦闘、探索がつながったところで、NPCが何を目的として行動するのかを具体化していこう。
