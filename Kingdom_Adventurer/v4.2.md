## 回答状況

未回答・検討中。以下の候補はすべて未決定。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 国家間の同盟

- **未決定・推奨** 国家が利害・外交関係に応じて同盟を自律締結・破棄
- **未決定** 同盟は存在するが国家間で固定
- **未決定** 同盟システムを設けない

<a id="q2"></a>
### 2. 同盟国の参戦

- **未決定・推奨** 同盟国は国益・関係・戦力を考慮して援軍を判断
- **未決定** 同盟国は必ず参戦
- **未決定** 同盟は外交上の関係のみで参戦しない

<a id="q3"></a>
### 3. 戦争による民間経済への影響

- **未決定・推奨** 戦闘地域の治安・交易・労働・物価が変動
- **未決定** 戦争は税収と人口にのみ影響
- **未決定** 戦争は軍事と領土だけに影響

<a id="q4"></a>
### 4. 反乱・独立

- **未決定・推奨** 住民の不満や国家の弱体化に応じて反乱・独立が発生
- **未決定** 国家崩壊時にのみ分裂
- **未決定** 反乱・独立は発生しない

<a id="q5"></a>
### 5. 外交交渉の手段

- **未決定・推奨** 国家間で同盟・通商・停戦・賠償などを条件交渉
- **未決定** 友好・敵対の関係値のみ管理
- **未決定** 外交は戦争と和平だけに限定

## 整合性と懸念

- v4.0で開戦の主条件は外交関係の悪化、占領地は即時に通常領地へ移行、和平は交渉式と確定。
- v4.1で軍隊補給なし、近距離は実戦闘・遠方は簡易計算と確定。
- 反乱・独立を導入する場合も占領地の即時通常統治と矛盾しないよう、反乱の発生条件を別に定義する。
