## 決定事項

> Kingdom Adventurer v2.2の経済・生産・交易仕様として、生産方式：原材料・加工品・完成品を実在アイテムとして管理。NPCの生活需要：食料・住居・衣服・道具・娯楽など複数需要。交易方式：商隊・船が実際に商品を運搬。NPCの商店・工房：NPCが自律的に開業・雇用・仕入れ・販売・廃業。貨幣・財産：NPC・商店・国家間で実際に貨幣を移転。これらを確定仕様として整理し、次の未確定事項を検討しよう。

## 確認事項と選択肢

<a id="q1"></a>

### 1. 生産品と在庫の管理

- **採用** 原材料から完成品まで実在アイテムとして管理
- **不採用** 生産量・在庫を集約数値で管理
- **不採用** 近距離は実物、遠距離は集約在庫（推奨）

<a id="q2"></a>

### 2. NPCの生活需要

- **採用** 食料・住居・衣服・道具・娯楽など（推奨）
- **不採用** 食料・住居を中心に管理
- **不採用** 生活費だけで抽象化

<a id="q3"></a>

### 3. 地域間の交易

- **採用** 商隊・船が実際に商品を運搬
- **不採用** 地域間取引を数値だけで処理
- **不採用** 実際の輸送＋遠方の簡略処理（推奨）

<a id="q4"></a>

### 4. NPCの商店・工房経営

- **採用** 開業・雇用・仕入れ・販売・廃業を自律判断（推奨）
- **不採用** 既存店舗のみ経営
- **不採用** 経営判断はプレイヤー中心

<a id="q5"></a>

### 5. 貨幣と財産の管理

- **採用** NPC・商店・国家間で実際に貨幣を移転（推奨）
- **不採用** 取引時に貨幣を生成・消滅
- **不採用** 基本は移転、必要時に経済補正

## 当時の要件・懸念・検討の経緯

以下は提案時点の記録。例や将来案も含むため、採用の有無は決定事項と選択肢欄を参照。

Kingdom Adventurer — 仕様案 v2.2

人口・世代交代仕様の確定／経済・生産・交易システムの詳細設計

v2.1の5項目を確定仕様に追加する。

これで、NPCが実際に家族を作り、子供が成長し、仕事や生活環境によって移住し、集落が自然に発展・衰退するという人口シミュレーションの基本構造が固まった。

次は、NPCたちが何を生産し、何を消費し、どのように経済を動かすかを決めよう。

#### 1. v2.1で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 人口増減 | 食料・住宅・雇用・治安などに連動 |
| 出生 | 実際のNPCの家族関係から発生 |
| 寿命 | 種族ごとに寿命・成長速度が異なる |
| 移住 | 仕事・生活・安全を考慮して自律移住 |
| 集落の発展 | 人口・資源・経済に応じて拡大・衰退 |

ここで重要なのは、人口を単なる数値として増減させないこと。

例えば村に子供が生まれた場合、その子には両親、出生地、種族、年齢などの情報があり、成長して仕事に就き、やがて新しい家族を作る。

遠方の村では計算を簡略化しても、個人情報と家族関係は保持する。

#### 2. 次のテーマ：経済・生産・交易

既に以下の経済仕様は確定している。

NPCは職業を持ち、働き、収入を得る。

生産・消費・売買には実際の資源やアイテムを使用する。

商品価格は需要・供給・地域によって変動する。

NPCは商店や工房を経営できる。

プレイヤーも商売・製造・雇用に参加できる。

戦争や交易路の変化が経済に影響する。

今回は、それらを実現するための具体的な仕組みを決める。

#### 3. 生産から消費までの流れ

例：村でパンが作られるまで

農家

小麦を生産

製粉所

小麦を小麦粉に加工

パン屋

小麦粉からパンを製造

住民

パンを購入して消費

生産工程の例。各工程の詳細は未確定。

この場合、農家が小麦を生産できなければ製粉所やパン屋も影響を受ける。

パンが不足すれば価格が上がり、住民の生活や人口増減にも影響する。

#### 4. 商隊による地域間交易

例えば、山岳都市には鉄鉱石が豊富でも食料が不足しやすい。

一方、農村には食料が豊富でも金属製品が不足する。

商人が両地域を行き来すれば、互いに必要な商品を交換できる。

交易路が魔物や戦争によって危険になれば、商品の輸送量が減り、価格や住民の生活が変化する。

このように、プレイヤーが護衛や交易に参加することにも実際の意味が生まれる。

#### 5. v2.2で確定したい5項目

#### 6. 今後の検討

経済システムが確定したら、次は戦闘・成長・魔法の詳細設計に進む。

その後は、NPCの意思決定、国家運営、ゲームバランス、技術構成などを整理していく。

なお、今回の選択肢①と③は、これまで決めた「実際の資源・アイテムを使う経済」との整合性が重要になる。

遠方で処理を簡略化する場合でも、商品や財産が無から生まれたり、理由なく消えたりしないことを基本方針として考えたい。
