## 確認事項と選択肢

<a id="q1"></a>
### 1. 家賃改定の提案者

- **未決定・推奨** 所有者と借主の双方が改定を提案でき、値上げ・値下げのどちらも交渉できる
- **未決定** 所有者だけが値上げを提案できる
- **未決定** 借主だけが値下げを提案できる

<a id="q2"></a>
### 2. 改定提案の1年制限の起算点

- **未決定・推奨** 最後に提案した日からゲーム内365日経過後に再提案できる
- **未決定** 毎年1月1日になれば直前の提案日を問わず再提案できる
- **未決定** 所有者が変わるたびに即日再提案できる

<a id="q3"></a>
### 3. 家賃改定の合意成立時

- **未決定・推奨** 合意した新家賃を次の月次支払日から適用し、既存契約は継続する
- **未決定** 合意した瞬間に過去の滞納額も新家賃で再計算する
- **未決定** 合意しても家賃は変更されない

<a id="q4"></a>
### 4. 住宅売買後の改定交渉

- **未決定・推奨** 新所有者は従前の契約と改定提案の制限を引き継ぐ
- **未決定** 売買直後に必ず契約を終了する
- **未決定** 所有者変更だけで家賃を自動的に倍額にする

<a id="q5"></a>
### 5. 交渉不成立の記録

- **未決定・推奨** 改定の提案内容・当事者・結果を住宅取引履歴に記録する
- **未決定** 合意した改定だけを記録し不成立の交渉は消去する
- **未決定** 交渉履歴は毎月すべて削除する

## 既存仕様との整合

- v6.1で契約は更新せず自動継続、所有者・借主の提案時だけ家賃改定を交渉すると確定。
- v6.1で改定提案は同じ住宅につきゲーム内1年に1回までと確定。
- v6.1で交渉不成立でも旧契約を継続し退去しないと確定。v6.0の旧決定を上書き。
- v6.0とv6.1で滞納債権の新所有者への移転と移転履歴の保存を確定。
