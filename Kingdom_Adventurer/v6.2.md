# v6.2 家賃改定提案・起算点・適用時期・売買後交渉・履歴

[目次](README.md) · [前の版](v6.1.md) · [不採用案の索引](option-index.md) · [次の版](v6.3.md)

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 家賃改定の提案者

- **採用・確定** 所有者と借主の双方が改定を提案でき、値上げ・値下げのどちらも交渉できる
- **不採用（再検討可）** 所有者だけが値上げを提案できる
- **不採用（再検討可）** 借主だけが値下げを提案できる

<a id="q2"></a>
### 2. 改定提案の1年制限の起算点

- **不採用（再検討可）** 最後に提案した日からゲーム内365日経過後に再提案できる
- **採用・確定** 毎年1月1日になれば直前の提案日を問わず再提案できる
- **不採用（再検討可）** 所有者が変わるたびに即日再提案できる

<a id="q3"></a>
### 3. 家賃改定の合意成立時

- **採用・確定** 合意した新家賃を次の月次支払日から適用し、既存契約は継続する
- **不採用（再検討可）** 合意した瞬間に過去の滞納額も新家賃で再計算する
- **不採用（再検討可）** 合意しても家賃は変更されない

<a id="q4"></a>
### 4. 住宅売買後の改定交渉

- **採用・確定** 新所有者は従前の契約と改定提案の制限を引き継ぐ
- **不採用（再検討可）** 売買直後に必ず契約を終了する
- **不採用（再検討可）** 所有者変更だけで家賃を自動的に倍額にする

<a id="q5"></a>
### 5. 交渉不成立の記録

- **採用・確定** 改定の提案内容・当事者・結果を住宅取引履歴に記録する
- **不採用（再検討可）** 合意した改定だけを記録し不成立の交渉は消去する
- **不採用（再検討可）** 交渉履歴は毎月すべて削除する

## 既存仕様との整合

- v6.1で契約は更新せず自動継続、所有者・借主の提案時だけ家賃改定を交渉すると確定。
- v6.1で改定提案は同じ住宅につきゲーム内1年に1回までと確定。
- v6.1で交渉不成立でも旧契約を継続し退去しないと確定。v6.0の旧決定を上書き。
- v6.0とv6.1で滞納債権の新所有者への移転と移転履歴の保存を確定。

## 確定内容の補足

- 所有者・借主の双方が家賃の値上げ・値下げを提案可能。
- **第2問は第2候補を採用**。同じ住宅の改定提案はゲーム内の暦年につき1回までとし、**毎年1月1日に再提案可能**になる。最後の提案日から365日を待つ方式ではない。v6.1の『1年に1回まで』を暦年単位として具体化する。
- 合意した新家賃は次の月次支払日から適用し、既存契約を継続する。過去の滞納額は再計算しない。
- 住宅売買後、新所有者は既存契約とその年の改定提案制限を引き継ぐ。
- 改定提案内容・当事者・交渉結果（合意・不成立）を住宅取引履歴に保存する。
