# v5.3 空き家・住宅売買・新築優先・廃村猶予中・世帯分離

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 移住住宅の再利用

- **採用・確定** 転居で空いた住宅は空き家として残り、別世帯が入居できる
- **不採用（再検討可）** 転居した瞬間に住宅を削除する
- **不採用（再検討可）** 空き家は所有者以外が一切使えない

<a id="q2"></a>
### 2. 住宅の売買・相続

- **採用・確定** 住宅はNPC間で売買・相続でき、所有権の移転を記録
- **不採用（再検討可）** 住宅は売買も相続もできない
- **不採用（再検討可）** 住宅の所有者は毎年ランダムに変わる

<a id="q3"></a>
### 3. 移住時の新築と空き家

- **採用・確定** 入居可能な空き家を優先し、なければ無償住宅を新築する
- **不採用（再検討可）** 空き家があっても必ず新築する
- **不採用（再検討可）** 空き家がなければ移住できない

<a id="q4"></a>
### 4. 廃村判定中の扱い

- **採用・確定** 人口ゼロの30日間は無人集落として建物・道路を保持し、再入植で猶予を解除
- **不採用（再検討可）** 人口ゼロになった瞬間に建物を削除する
- **不採用（再検討可）** 猶予期間中は集落を地図から非表示にする

<a id="q5"></a>
### 5. 移住住宅の世帯分離

- **採用・確定** 家族の独立・結婚などで別世帯になった場合は必要に応じて住宅を確保
- **不採用（再検討可）** 同じ家族は生涯一つの住宅で暮らす
- **不採用（再検討可）** 世帯分離のたびに集落を移動する

## 既存仕様との整合

- v5.2で住宅は移住者世帯が所有し、収入・家族構成・立地に応じて住み替え可能と確定。
- v5.0〜v5.2で移住時の最低限住宅は無償・無資源で自動生成し、宅地は地形・国境の制約を受けると確定。
- v5.2で定住人口ゼロが30日続くと廃村化、v5.0で廃村化時に建物を削除すると確定。

## 確定内容の補足

- 転居後の住宅は空き家として残り、入居可能な別世帯が利用できる。所有権は自動的には消滅せず、売買・相続による移転を記録する。
- 移住時は入居可能な空き家を優先し、なければv5.0の無償・無資源の最低限住宅を新築する。
- 定住人口ゼロの30日間は無人集落として建物・道路を保持し、再入植で猶予を解除する。30日間連続でゼロなら廃村化して建物を削除（v5.0〜v5.2）。
- 独立・結婚等の世帯分離では必要に応じて住宅を確保する。
