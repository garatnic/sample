## 確認事項と選択肢

<a id="q1"></a>
### 1. 軍隊の移動と遠距離処理

- **未決定・推奨** 近距離は部隊を実際に移動、遠距離は移動時間と戦力で簡易計算
- **未決定** すべての軍隊を常時マップ上で実移動
- **未決定** 軍隊移動はすべて抽象的に計算

<a id="q2"></a>
### 2. 軍隊の補給

- **未決定・推奨** 食料・物資を実在庫から消費し、補給線が途絶えると戦力低下
- **未決定** 補給は維持費だけで表現
- **未決定** 補給の概念を設けない

<a id="q3"></a>
### 3. 城・都市への攻撃

- **未決定・推奨** 城壁や守備力を数値化し、包囲と突撃を簡易処理
- **未決定** 城攻めも野戦と同じ戦力比較
- **未決定** 城内で兵士単位の攻城戦を詳細にシミュレーション

<a id="q4"></a>
### 4. 大規模戦闘の処理

- **未決定・推奨** プレイヤー付近は実戦闘、遠方は兵数・戦力・地形などで簡易決着
- **未決定** すべての戦場を実戦闘で処理
- **未決定** すべての戦闘を数値のみで決着

<a id="q5"></a>
### 5. プレイヤーの戦争参加

- **未決定・推奨** 一兵士・傭兵・指揮官・国家指導者など立場に応じ参加可能
- **未決定** 国家指導者として命令する場合のみ参加
- **未決定** 冒険者として戦場に参加するが軍の指揮はできない

## 既存仕様との整合

- v4.0では軍隊の編成を兵数と総合戦力のみで管理すると確定。
- v3.9では国家が実際の国庫を持ち、予算を自律配分すると確定。
- 近距離を詳しく、遠距離を簡略化する世界シミュレーション方針との整合を確認する。
