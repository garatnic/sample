## 確認事項と選択肢

<a id="q1"></a>
### 1. 宅地拡張の上限

- **未決定・推奨** 地形・通行可能性・他国領を考慮し、拡張可能な場所に限って宅地を増やす
- **未決定** 地形・国境を無視して無限に宅地を増やす
- **未決定** 集落の外側には宅地を拡張できない

<a id="q2"></a>
### 2. 移住住宅の所有権

- **未決定・推奨** 生成された住宅は移住者世帯の所有物になる
- **未決定** 生成住宅はすべて国家の所有物になる
- **未決定** 住宅は所有者を持たず自由に使用できる

<a id="q3"></a>
### 3. 移住住宅からの転居

- **未決定・推奨** NPCは収入・家族構成・立地に応じて通常の住宅へ住み替え可能
- **未決定** 移住時の住宅に一生住み続ける
- **未決定** NPCは毎年必ず新しい住宅に移る

<a id="q4"></a>
### 4. 廃村化の猶予日数

- **未決定・推奨** ゲーム内30日間、定住人口ゼロが続いた場合に廃村化
- **未決定** ゲーム内1日で廃村化
- **未決定** ゲーム内365日で廃村化

<a id="q5"></a>
### 5. 再入植時の集落名称

- **未決定・推奨** 旧集落名を基本的に引き継ぎ、歴史上は再建として記録
- **未決定** 再入植のたびに必ず新しい名前にする
- **未決定** 集落名を付けず番号だけで管理する

## 既存仕様との整合

- v5.1で宅地不足時の周辺拡張、世界共通住宅モデル、廃村化猶予、廃村跡の再入植、移住時住宅のみ無償生成を確定。
- v5.0で廃村化後も地形・道路・土地履歴・年代記は保持する。
- v5.2は無制限住宅生成と物理的な土地制約の両立、住宅所有、具体的な廃村日数を決める。
