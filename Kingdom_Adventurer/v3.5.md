## 確認事項と選択肢

<a id="q1"></a>

### 1. 通常攻撃の対象選択

- **採用** 基本は自動選択、手動指定も可能（推奨）
- **不採用** すべて手動で指定
- **不採用** 常に最も近い敵を自動攻撃

<a id="q2"></a>

### 2. スキルの自動使用

- **採用** HP・MP・敵の状況などの条件を設定可能（推奨）
- **不採用** 自動使用のオン・オフのみ
- **不採用** すべて手動使用

<a id="q3"></a>

### 3. 戦闘難易度の調整方法

- **採用** 敵の能力値・攻撃力・耐久力などを調整（推奨）
- **不採用** 敵のAI判断能力を中心に調整
- **不採用** 敵の能力値とAI判断能力の両方を調整

<a id="q4"></a>

### 4. 敵の撤退・降伏判断

- **採用** HP・戦力差・性格・状況に応じて判断（推奨）
- **不採用** HPが一定以下になると撤退
- **不採用** 基本的に最後まで戦う

<a id="q5"></a>

### 5. 敵集団の連携

- **採用** 前衛・後衛・支援など役割に応じて連携（推奨）
- **不採用** 各敵が独立して戦う
- **不採用** 包囲・陽動・集中攻撃など高度な戦術を使用

Kingdom Adventurer — 仕様案 v3.5

キャラクター成長仕様の確定／戦闘AI・難易度・戦闘バランス

v3.4の5項目を確定仕様に追加する。

これで、職業に縛られず、あらゆる技能を習得できる自由育成型RPGという方向性が固まった。

#### 1. v3.4で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 職業 | 固定職業なし。技能の組み合わせで自由育成 |
| レベルと技能 | レベルで基礎能力、熟練度で専門能力が成長 |
| 技能制限 | すべての技能を習得・成長可能 |
| 魔法習得 | 魔法書・教師・研究・実践などで習得 |
| 成長速度 | 初期は伸びやすく、高熟練度ほど成長が緩やかになる |

育成の基本方針

例えば、剣術を極めた冒険者が途中から魔法を学んだり、鍛冶職人が冒険者として活動したりできる。

ただし、すべての技能を習得できることと、短期間ですべてを極められることは別。

高熟練度ほど成長が緩やかになるため、専門分野を持つことにも意味がある。

#### 2. 次のテーマ：戦闘AIと難易度

これまでに確定している戦闘仕様は次のとおり。

リアルタイムの半自動戦闘。

通常攻撃は自動、スキルは手動・自動を切り替え可能。

敵の強さはプレイヤーレベルに連動しない。

魔物は基本的に敵対的。

敵は状況によって撤退・降伏する。

敵の種類・性格・経験に応じて行動が変化する。

敵集団は役割分担や連携を行う。

仲間ごとに戦闘方針を設定できる。

雇用・同行中の仲間は永久死亡しない。

今回は、戦闘中の判断や、難易度をどのように調整するかを決める。

#### 3. 戦闘のイメージ

敵集団との遭遇

例えば、敵集団に前衛・弓兵・魔法使いがいる場合、それぞれの能力に応じた行動を取る。

前衛は接近して攻撃する。

弓兵は距離を保って攻撃する。

魔法使いは攻撃・回復・強化などを使用する。

不利になった敵は逃走や降伏を検討する。

戦闘AIの動作例。細かな判断条件は未確定。

戦闘を難しくする方法には、敵の能力を上げる方法と、敵の判断を賢くする方法がある。

ただし、敵の能力が極端に高くなるだけでは、戦闘が単調になる可能性がある。

そこで今回は、操作の快適さを保ちながら、戦闘にどの程度の戦術性を持たせるかを選ぶ。
