## 確認事項と選択肢

<a id="q1"></a>
### 1. 国家の初期配置

- **未決定・推奨** 世界生成時に地形・資源・人口を考慮して国家と未所属地を配置
- **未決定** 世界全体を最初から国家領土で埋める
- **未決定** 国家は存在せずNPCがゼロから建国する

<a id="q2"></a>
### 2. 国家の拡張方法

- **未決定・推奨** 未所属地には平和的に進出でき、他国領は戦争・和平で獲得
- **未決定** 未所属地も軍隊による占領が必要
- **未決定** 国家の領土は戦争でのみ拡張できる

<a id="q3"></a>
### 3. 国境の表現

- **未決定・推奨** 地図上に領土境界を表示し、支配権を地域単位で管理
- **未決定** 国境は都市・拠点の所属だけで表現
- **未決定** 国境を表示せず国家名のみ管理

<a id="q4"></a>
### 4. 国家指導者の意思決定

- **未決定・推奨** 外交・軍事・内政を指導者の性格・能力・国家状況で自律判断
- **未決定** 国家状況の数値だけで機械的に判断
- **未決定** 国家の重要行動はプレイヤーが指示した場合のみ実行

<a id="q5"></a>
### 5. 国家の歴史記録

- **未決定・推奨** 建国・統合・戦争・滅亡・指導者交代を年代記として保存
- **未決定** 国家の現在状態のみ保存
- **未決定** 国家の歴史は建国と滅亡だけ保存

## 整合性と懸念

- v4.3では未所属地での建国、全領土喪失による滅亡、自律国家統合を採用。
- v4.4では未所属地・人口・資金等を建国条件とし、国家消滅後も住民・施設・歴史を残す。
- v4.2で反乱・独立は不採用。国家の増減は建国・統合・征服・滅亡で表現する。
