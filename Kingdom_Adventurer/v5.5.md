## 確認事項と選択肢

<a id="q1"></a>
### 1. 住宅の賃貸料の決め方

- **未決定・推奨** 立地・広さ・地域の需給・所有者の希望で家賃が変動する
- **未決定** 世界中の住宅で家賃を一律固定
- **未決定** 賃貸住宅の家賃は必ず無料

<a id="q2"></a>
### 2. 住宅売買の価格

- **未決定・推奨** 広さ・立地・地域需要・取引履歴を考慮して価格を決める
- **未決定** すべての住宅を同一価格で売買
- **未決定** 住宅の売買は常に無償

<a id="q3"></a>
### 3. 住宅の複数所有

- **未決定・推奨** NPCは資金に応じて複数の住宅を所有・賃貸できる
- **未決定** NPCは必ず住宅を一軒しか所有できない
- **未決定** 住宅所有数に上限はないが売買・賃貸は不可

<a id="q4"></a>
### 4. 住宅の損壊と経年劣化の区別

- **未決定・推奨** 経年劣化はしないが災害・戦闘などの直接被害では損壊し得る
- **未決定** 災害・戦闘を含め住宅は一切損壊しない
- **未決定** 経年劣化だけ発生し、災害では損壊しない

<a id="q5"></a>
### 5. 移住者の空き家選択

- **未決定・推奨** 価格・立地・広さ・家族構成・契約条件を比較して入居先を選ぶ
- **未決定** 最初に見つかった空き家へ必ず入居
- **未決定** 空き家の割り当ては完全にランダム

## 既存仕様との整合

- v5.3で空き家を優先し、なければ移住時の最低限住宅を無償新築する方針を確定。
