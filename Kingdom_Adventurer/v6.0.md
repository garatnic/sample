# v6.0 契約更新周期・改定不成立・債権譲渡・相続人不在・履歴保存

[目次](README.md) · [前の版](v5.9.md) · [不採用案の索引](option-index.md) · [次の版](v6.1.md)

## 回答状況

2026-11-24 ユーザー回答により5項目すべて確定。全候補と不採用案を保持。

## 確認事項と選択肢

<a id="q1"></a>
### 1. 契約更新の周期

- **不採用（再検討可）** 賃貸契約はゲーム内1年ごとに更新判定し、家賃改定は更新時に行う
- **不採用（再検討可）** 毎日契約を更新し家賃を見直す
- **採用・確定** 賃貸契約は更新を一切行わない

<a id="q2"></a>
### 2. 家賃改定で合意できない場合

- **不採用（再検討可）** 従来条件で契約を継続し、次回更新時に再交渉する
- **採用・確定** 借主を即時退去させる
- **不採用（再検討可）** 所有者の提示額を強制適用する

<a id="q3"></a>
### 3. 滞納債権の譲渡

- **不採用（再検討可）** 旧所有者が持つ滞納債権は当事者の合意により新所有者などへ譲渡できる
- **採用・確定** 滞納債権は無条件に新所有者へ移る
- **不採用（再検討可）** 滞納債権は売買や相続のたびに消滅する

<a id="q4"></a>
### 4. 相続人がいない家賃債務

- **採用・確定** 借主死亡時に相続人がいなければ遺産の範囲で精算し、未回収分は回収不能として記録する
- **不採用（再検討可）** 相続人がいない場合は無関係のNPCに負債を負わせる
- **不採用（再検討可）** 相続人がいなくても故人から永久に家賃を徴収する

<a id="q5"></a>
### 5. 住宅取引履歴の保存範囲

- **採用・確定** 住宅消滅後もNPC・集落の履歴に取引情報を残し、年代記から検索できる
- **不採用（再検討可）** 住宅が消滅すると取引履歴も削除する
- **不採用（再検討可）** 現在の所有者だけ記録し過去の履歴は残さない

## 既存仕様との整合

- v5.9で家賃改定は契約更新時の市場相場と双方の合意に基づくと確定。
- v5.9で過去の滞納債権は原則として旧所有者に残り、借主死亡時は同居世帯員が契約を引き継げると確定。
- v5.8で家賃負債は相続財産とともに相続順位に応じて扱うと確定。
- v5.7で廃村化後も過去の賃貸契約履歴を保持すると確定。

## 確定内容の補足と旧版からの変更

- **第1問は第3候補を採用**。賃貸契約は更新を一切行わない。
- **第2問は第2候補を採用**。家賃改定で合意できなければ借主は即時退去する。家賃滞納そのものでは退去させないというv5.6〜v5.9の方針は維持する。
- **第3問は第2候補を採用**。住宅売買・相続で所有者が変わった場合、滞納債権は無条件に新所有者へ移る。**v5.9の『原則として旧所有者に残す』を上書きする**。旧版の決定は履歴として保持する。
- 相続人がいない借主の死亡時は遺産の範囲で家賃債務を精算し、未回収分を回収不能として記録する。
- 住宅消滅後もNPC・集落の取引履歴を保持し、年代記から検索できる。
- **未解決の整合事項**：v5.9では『契約更新時に家賃改定』としていたが、v6.0では『契約更新なし』としたため、更新を伴わない家賃改定交渉の発生条件・時期を次版で検討する。
