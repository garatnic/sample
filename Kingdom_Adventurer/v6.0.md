## 確認事項と選択肢

<a id="q1"></a>
### 1. 契約更新の周期

- **未決定・推奨** 賃貸契約はゲーム内1年ごとに更新判定し、家賃改定は更新時に行う
- **未決定** 毎日契約を更新し家賃を見直す
- **未決定** 賃貸契約は更新を一切行わない

<a id="q2"></a>
### 2. 家賃改定で合意できない場合

- **未決定・推奨** 従来条件で契約を継続し、次回更新時に再交渉する
- **未決定** 借主を即時退去させる
- **未決定** 所有者の提示額を強制適用する

<a id="q3"></a>
### 3. 滞納債権の譲渡

- **未決定・推奨** 旧所有者が持つ滞納債権は当事者の合意により新所有者などへ譲渡できる
- **未決定** 滞納債権は無条件に新所有者へ移る
- **未決定** 滞納債権は売買や相続のたびに消滅する

<a id="q4"></a>
### 4. 相続人がいない家賃債務

- **未決定・推奨** 借主死亡時に相続人がいなければ遺産の範囲で精算し、未回収分は回収不能として記録する
- **未決定** 相続人がいない場合は無関係のNPCに負債を負わせる
- **未決定** 相続人がいなくても故人から永久に家賃を徴収する

<a id="q5"></a>
### 5. 住宅取引履歴の保存範囲

- **未決定・推奨** 住宅消滅後もNPC・集落の履歴に取引情報を残し、年代記から検索できる
- **未決定** 住宅が消滅すると取引履歴も削除する
- **未決定** 現在の所有者だけ記録し過去の履歴は残さない

## 既存仕様との整合

- v5.9で家賃改定は契約更新時の市場相場と双方の合意に基づくと確定。
- v5.9で過去の滞納債権は原則として旧所有者に残り、借主死亡時は同居世帯員が契約を引き継げると確定。
- v5.8で家賃負債は相続財産とともに相続順位に応じて扱うと確定。
- v5.7で廃村化後も過去の賃貸契約履歴を保持すると確定。
