## 確認事項と選択肢

<a id="q1"></a>

### 1. NPCとの会話方式

- **採用** 状況に応じた選択肢式会話（推奨）
- **不採用** 自由入力による会話
- **不採用** 選択肢式＋自由入力の併用

<a id="q2"></a>

### 2. 交渉の成否と条件

- **採用** 交渉技能・友好度・性格・状況に応じる（推奨）
- **不採用** 友好度のみで決定
- **不採用** 交渉条件は固定

<a id="q3"></a>

### 3. NPCとの依頼関係

- **採用** プレイヤーとNPCが互いに依頼を出せる（推奨）
- **不採用** NPCからの依頼を受けるのみ
- **不採用** プレイヤーからの依頼中心

<a id="q4"></a>

### 4. 噂・情報の扱い

- **採用** 世界情報は共有し、噂は会話・演出に利用（推奨）
- **不採用** 噂が伝播して初めて情報を利用可能
- **不採用** 噂システムなし

<a id="q5"></a>

### 5. 友好度の変化

- **採用** 行動・会話・取引・時間経過で変化（推奨）
- **不採用** 重要な行動のみで変化
- **不採用** クエスト結果でのみ変化

Kingdom Adventurer — 仕様案 v2.8

NPC意思決定仕様の確定／会話・交渉・依頼システム

v2.7の5項目を確定仕様に追加する。

今回は、NPCの性格や人生の目標は複雑にする一方、人間関係は単一の友好度で管理し、NPCは世界全体の情報を利用して判断するという方針になった。

これにより、NPCの行動に個性を持たせながら、情報伝達や人間関係の計算を比較的シンプルにできる。

#### 1. v2.7で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 性格 | 複数の性格パラメータを組み合わせる |
| 人生の目標 | 状況や経験に応じて変化 |
| 記憶 | 重要な出来事や人物との関係を長期保存 |
| 人間関係 | 友好度の単一数値で管理 |

情報認識について

「世界の全情報を把握」とは、NPCの意思決定に世界全体の状態を利用できるという意味で扱う。

例えば、遠方で戦争が始まれば、その情報を使って移住や商売の判断ができる。

ただし、これまでの犯罪システムで確定した「犯罪の発覚には目撃・証拠・通報が必要」という仕様は維持する。

そのため、行動判断に利用できる世界情報と、犯罪の証拠・法的認定は別の仕組みとして扱う。

#### 2. 次のテーマ：NPCとの会話・交渉・依頼

NPCが自律的に生活する世界では、プレイヤーとの会話も重要になる。

例えば、村の鍛冶師に話しかければ、商品の購入だけでなく、仕事の依頼、雇用の交渉、地域の状況についての質問などができると面白い。

今回は、そうしたNPCとの交流方法を決める。

#### 3. 会話と交渉のイメージ

NPC：鍛冶師エドガー

友好度：+35（説明用）

「最近、鉄鉱石が不足していてね。鉱山から仕入れてきてくれるなら、代金を払うよ。」

仕事を引き受ける

報酬について交渉する

商品を見せてもらう

近くの鉱山について尋ねる

会話画面の構想例。実際のUIや会話文は未確定。

既存仕様では、クエストは実際の世界状況から生成され、報酬は依頼者の実際の財産から支払われる。

そのため、上の例で鍛冶師が報酬を提示する場合も、鍛冶師自身の所持金や経営状況が関係する。

#### 5. 次に検討すること

会話・交渉仕様が固まったら、次は国家・政治・外交・戦争の詳細設計へ進む。

既に国家の成立・崩壊・分裂・統合、戦争、領地運営、国家建設などは基本仕様として確定している。

次は、国家がどのように意思決定し、領土を拡大し、政治や外交を進めるのかを具体化していこう。
