## 確認事項と選択肢

<a id="q1"></a>
### 1. 空き家への入居契約

- **未決定・推奨** 所有者の同意を得て購入・賃貸・無償貸与などで入居する
- **未決定** 空き家は所有者の同意なく自由に占有できる
- **未決定** 空き家は売買でしか入居できない

<a id="q2"></a>
### 2. 住宅の相続先

- **未決定・推奨** 家族・親族関係と相続順位に基づき所有権を引き継ぐ
- **未決定** 住宅は死亡時に必ず国家へ移る
- **未決定** 死亡のたびにランダムなNPCへ譲渡する

<a id="q3"></a>
### 3. 所有者不在の住宅

- **未決定・推奨** 相続人・所有者がいなければ集落管理の空き家として再利用する
- **未決定** 所有者不在でも永久に利用不可とする
- **未決定** 所有者不在になった瞬間に住宅を削除する

<a id="q4"></a>
### 4. 住宅の維持と劣化

- **未決定・推奨** 通常住宅は時間経過で劣化し、維持管理・修繕で状態を回復する
- **未決定** 住宅は建築後永久に劣化しない
- **未決定** 住宅は一定日数で必ず自動消滅する

<a id="q5"></a>
### 5. 空き家不足時の移住住宅生成

- **未決定・推奨** 入居可能な空き家がなく宅地を確保できれば無償新築し、土地がなければ別の移住先を検討する
- **未決定** 宅地がなくても既存建物に重ねて新築する
- **未決定** 空き家不足なら移住自体を永久に禁止する

## 既存仕様との整合

- v5.2で移住住宅は移住者世帯が所有し、NPCは転居可能と確定。
- v5.3で空き家の再利用、住宅売買・相続、空き家優先の移住住宅確保を確定。
- v5.0〜v5.2で移住時の最低限住宅は無償・無資源、宅地の拡張は地形・国境などの物理制約を受ける。
