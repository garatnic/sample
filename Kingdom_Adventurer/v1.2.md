## 当時の要件・懸念・検討の経緯

Kingdom Adventurer — 仕様案 v1.2

建築・領地経営仕様の確定／国家・外交・戦争システムの設計

v1.1の5項目を確定仕様に追加した。

今回の重要な決定は、プレイヤーだけでなくNPCも自律的に土地を利用し、建築・移住・集落発展を進めること。

これにより、プレイヤーが冒険している間にも、新しい村が生まれ、既存の町が発展し、戦争によって建物が破壊されるような世界を実現する方針になる。

#### 1. v1.1で確定した仕様

| 項目 | 確定内容 |
| --- | --- |
| 建築 | 土地条件を満たせば自由配置 |
| 土地所有 | 未所有地は自由に占有可能 |
| 集落発展 | NPCが自律的に建築・移住・発展 |
| 領地管理 | NPCに委任可能。直接管理も可能 |
| 建築物 | 損傷・破壊・修復あり |

ここでいう未所有地は、所有者が設定されていない土地を指す。既存の国家領土と未所有地の関係や、占有後の領有権争いについては、国家システム側で整理する。

また、建物は損傷するが、装備には耐久度がないという既存仕様は維持する。

#### 2. 国家システムの基本構想

世界には複数の国家が存在し、それぞれが人口、領土、資源、軍事力、外交関係を持つ。

国家はプレイヤーの行動とは無関係に、経済状況や他国との関係によって変化していく。

例えば、豊かな交易都市を持つ国家は経済的に成長する一方、魔物の侵攻で農村が荒廃した国家は食料不足に陥る可能性がある。

国家が持つ情報

| 分野 | 主なデータ |
| --- | --- |
| 領土 | 国境、都市、村、未開拓地 |
| 政治 | 君主、貴族、法律、統治方針 |
| 経済 | 国庫、税収、資源、生産力 |
| 軍事 | 常備軍、民兵、兵站、城塞 |
| 外交 | 同盟、敵対、条約、交易関係 |
| 社会 | 人口、治安、支持、文化 |

国家の興亡も歴史として記録し、何世代も経過したときに世界地図が変わっていることを目指す。

#### 3. 国家間の戦争

戦争は単純に兵力数値を比較するだけではなく、軍隊が実際に移動し、都市や拠点を攻略する仕組みを提案する。

ただし、プレイヤーが近くにいる場合と遠くにいる場合で処理を切り替える。

近距離：実際の戦闘

兵士がフィールド上に表示され、移動・攻撃・撤退を行う。プレイヤーも戦闘に参加できる。

遠距離：戦闘の簡易計算

部隊数、兵力、装備、地形、士気、補給などをもとに戦闘結果を計算する。

どちらの場合も、兵士の死亡、建物の破壊、物資の消費、領土の変化は共通の世界データに反映する。

#### 4. プレイヤーと国家の関係

プレイヤーは必ずしも国家に所属する必要はない。

自由冒険者

国家に属さず、各地を探索・交易する。

国家所属

兵士、傭兵、騎士などとして国家に仕える。

領主

国家から領地を与えられ、地域を統治する。

君主

独立国家を建国したり、既存国家の君主となったりする。

君主や領主になっても、プレイヤー自身がフィールドを歩いて冒険できることは維持する。

#### 5. 次に確定したい5項目

今回は、国家の変化と戦争の自由度を決める。

#### 6. 今後の設計

国家システムが確定したら、次は犯罪・法律・評判・社会的立場を検討したい。

例えば、盗賊として活動すれば指名手配され、国家によっては入国を拒否される。一方、ある国で犯罪者でも、敵対国家では英雄として扱われる可能性がある。

こうした仕組みを作れば、プレイヤーの行動が世界に影響し、冒険者・商人・傭兵・盗賊・領主・君主など、さまざまな生き方が成立するゲームに近づけられる。
